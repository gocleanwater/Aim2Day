# Aim2Day 요구사항 명세서

## 1. 목적

사용자가 달력연도 기준 목표를 월간·주간 목표와 오늘의 핵심 행동으로 구체화해 중요한 목표에 집중하도록 한다. 실제 행동 기록과 사용자가 확인한 연간 목표 달성 기준을 구분해 진행 상황을 보여준다.

## 2. 핵심 철학

> 중요하지 않지만 급한 일에 빠지지 않고, 중요한 목표에만 정말 집중하는 삶을 살아가도록 돕는다.

Aim2Day에서 `중요한 행동`은 사용자가 선택한 연간 목표와 연결되어 장기적인 변화를 만드는 행동을 의미한다. 단순히 마감이 가깝거나 즉시 처리해야 한다는 이유만으로 중요한 행동으로 분류하지 않는다.

모든 기능과 화면은 다음 원칙을 따라야 한다.

1. 올해 목표와 그 달성 기준, 이번 달 목표, 주간 목표, 오늘 해내고 싶은 행동까지 연결 관계를 확인할 수 있어야 한다.
2. 사용자가 매일 주간 목표에 연결해 오늘 해내고 싶은 행동을 자유롭게 작성하고, 하나씩 완료하며 필요할 때 행동을 추가할 수 있어야 한다. 행동의 순서나 우선순위, 활성화 여부를 별도로 선택하지 않는다.
3. 장기 목표와 직접 연결되지 않는 생활 업무는 `Maintenance`로 분리한다.
4. `Maintenance` 완료는 목표 진행률이나 집중 성과에 반영하지 않는다.
5. 오늘·주·월 계획과 `Maintenance`를 구분해 보여준다. 오늘 행동의 우선순위를 강제하지 않으며, 연간 목표의 표시 순서는 사용자가 직접 정할 수 있다.
6. 완료한 항목의 개수 자체를 성과로 과장하지 않는다.
7. AI는 목표와 관련성이 낮은 행동의 수정·이동·삭제를 제안할 수 있지만 사용자의 확인 없이 변경하지 않는다.

## 3. 사용자

### 비회원

- 회원가입할 수 있다.
- 로그인할 수 있다.

### 회원

- 같은 달력연도에 연간 목표를 최대 3개까지 만들 수 있다.
- 목표를 계층적으로 관리할 수 있다.
- 주간 목표에 연결된 오늘의 핵심 행동을 관리할 수 있다.
- 장기 목표와 직접 연결되지 않는 생활 업무를 별도로 관리할 수 있다.
- 전체 목표의 진행 상황과 기록을 확인할 수 있다.

### 목표 관리

| ID | 요구사항 | 우선순위 |
|---|---|---|
| GOAL-001 | 사용자는 같은 달력연도에 연간 목표를 최대 3개까지 만들 수 있어야 한다. 한도는 해당 사용자의 그 연도 목표 중 소프트 삭제되지 않은 목표를 상태(진행·완료·보류·중단)와 관계없이 합산한다. 소프트 삭제된 목표는 합산에서 제외하지만 복원할 때는 한도를 다시 검사한다. 한도에 도달하면 신규 목표 생성과 한도 초과 복원을 차단하고, 현재 사용 개수와 최대 개수 및 목표 삭제 등 가능한 조치를 명확히 안내한다. 이 제한은 연간 목표에만 적용한다. | 필수 |
| GOAL-002 | 목표 계층은 달력연도 기준 연간 목표 → 달력 월간 목표 → 주간 목표 → 오늘의 핵심 행동으로 구성한다. 6개월 및 임의 중간 목표 단계는 제공하지 않는다. | 필수 |
| GOAL-003 | 목표는 바로 위 단계의 부모 목표에 연결할 수 있어야 한다. | 필수 |
| GOAL-004 | 사용자는 자신이 만든 목표만 조회·수정·삭제할 수 있어야 한다. | 필수 |
| GOAL-005 | 목표에는 제목, 설명, 기간, 상태를 저장해야 한다. 연간 목표 기간은 매년 1월 1일부터 12월 31일까지이며, 새 월간 목표 기간은 생성 시점의 현재 달 전체다. | 필수 |
| GOAL-006 | 연간 목표 기간은 고정된 달력연도(1월 1일~12월 31일)다. 첫 방문 온보딩에서 올해 남은 기간에 집중할 목표를 작성하며, 이미 올해 목표가 있으면 기존 목표도 적을 수 있다. ‘남은 기간’은 안내 표현이며 연간 기간을 바꾸지 않는다. 온보딩에서는 연간 달성 기준이나 배점 확정을 요구하지 않는다. 기준과 배점 합계 100점을 확정하기 전 연간 목표 진행률은 퍼센트 대신 `달성 기준 설정하기`(또는 설정 전 상태)로 표시한다. 사용자가 기준과 배점 합계 100점을 확정하면 기본 진행률 0%를 최초 기준선으로 저장한다. 이때 사용자가 선택적으로 이미 달성한 기준을 확인하면 해당 배점을 최초 기준선에 반영한다. 최초 기준선 이후의 변화만 기록 시작 이후 변화로 표시하며 연초부터의 전체 성과로 오인되지 않게 한다. 가입 전 행동 이력은 추정하지 않는다. 하위 목표 기간은 부모 기간과 겹쳐야 한다. 월 경계를 넘는 주간 목표는 분할하지 않고, 겹치는 월간 목표 중 사용자가 선택한 한 곳에 연결한다. 연말 경계 주간에도 같은 규칙을 적용한다. | 필수 |
| GOAL-007 | 목표 삭제는 하위 목표가 있으면 확인 절차를 거쳐야 한다. | 필수 |
| GOAL-008 | 목표 삭제 시 즉시 물리 삭제하지 않고 삭제 시각을 기록해 휴지통으로 옮긴다. 삭제 시각부터 30일 동안 복원할 수 있다. 복원하지 않으면 30일 뒤 해당 목표 경로의 앞으로의 계획과 미완료 행동을 영구 삭제하고, 완료한 목표·행동과 이미 달성한 기준의 기록은 과거 이력으로 보존한다. 이력에는 당시 목표 이름과 수행일 또는 완료일을 남겨 리포트가 과거 사실을 계속 설명할 수 있게 한다. 영구 삭제 후에는 계획을 복원할 수 없음을 안내한다. 소프트 삭제 목표는 GOAL-001의 연간 목표 개수 한도에서 제외하며, 복원 시에는 해당 연도의 한도를 다시 검사한다. | 필수 |
| GOAL-009 | 사용자는 목표를 완료·보류·중단 상태로 변경할 수 있어야 한다. | 필수 |
| GOAL-010 | 사용자에게 보이는 날짜·기간 레이블은 연간 `2026년`(해당 연도), 월간 `2026.11`, 일간 `2026.11.10` 형식으로 표시한다. 날짜 범위가 필요한 주간 기간은 시작일과 종료일을 함께 명확히 표시한다. | 필수 |
| GOAL-011 | 사용자는 목표별 표시 이름(목표 제목)과 색상을 설정·수정할 수 있어야 한다. 달력과 일정 목록은 연결된 목표의 이름과 색상을 일관되게 사용한다. | 필수 |
| GOAL-012 | 연간·월간·주간 목표 상세에서 사용자는 목표를 수정하고 소프트 삭제할 수 있어야 하며, 삭제된 목표 목록에서 복원할 수 있어야 한다. 삭제 확인과 삭제·복원 결과를 명확히 표시한다. 연간 목표 복원은 GOAL-001의 한도를 다시 검사한다. | 필수 |
| GOAL-013 | 상위 목표를 소프트 삭제하면 하위 목표와 그 목표 경로에 연결된 미완료 핵심 행동을 일반 목록과 선택 화면에서 숨긴다. 30일 이내 상위 목표를 복원하면 기존 하위 목표와 연결된 미완료 행동을 다시 표시한다. 복구 기간 중에는 하위 항목과 행동을 물리 삭제하거나 연결을 변경하지 않는다. 30일 뒤에는 미래 계획과 미완료 행동만 영구 삭제하며, 완료한 목표·행동·달성 기준은 더 이상 활성 계획에 연결되지 않는 과거 이력으로 보존한다. 이력 보존이 필요한 목표 이름과 당시 달성 기준 값도 함께 보존한다. | 필수 |
| GOAL-014 | 새 월간 목표는 항상 현재 달을 대상으로 생성한다. 생성 화면은 대상 월을 입력받지 않으며 월간 목표 기간은 현재 달의 첫날부터 마지막 날까지다. | 필수 |

### 기간 시작과 계획

| ID | 요구사항 | 우선순위 |
|---|---|---|
| PLAN-001 | 주 시작 요일 기본값은 일요일이다. 사용자는 설정에서 일요일부터 토요일까지 선택할 수 있고, 이번 주·오늘·달력의 주 경계에 같은 선택을 적용한다. 설정을 바꿔도 이미 만든 주간 목표의 기간은 유지하고, 이후 새로 만드는 주간 목표부터 바뀐 시작 요일을 적용한다. | 필수 |
| PLAN-002 | 사용자는 올해 목표를 최대 3개까지 등록하고 목표마다 사용자 정의 달성 기준과 배정 비중을 설정할 수 있다. 기준과 배점 확정은 온보딩 필수가 아니며, 합계 100점을 확정하기 전 연간 진행률은 `달성 기준 설정하기`(또는 설정 전 상태)로 표시한다. 확정 시 기본 진행률 0%를 최초 기준선으로 저장하고, 사용자가 선택적으로 이미 달성한 기준을 표시하면 해당 배점을 반영한다. 이후 리포트는 최초 기준선 이후의 변화만 기록 시작 이후 변화로 표시하며 가입 전 행동 이력을 추정하지 않는다. 첫 방문 온보딩은 순서대로 네 질문에 답하는 한 경로로 제공한다: (1) 1월에는 “올해 어떤 일에 집중하고 싶나요?”, 2~12월에는 “올해 남은 기간에 어떤 일에 집중하고 싶나요?” (2) “그 목표를 위해 이번 달에 이루고 싶은 건 무엇인가요?” (3) “이번 주에는 어떤 결과를 만들고 싶나요?” (4) “그러면 오늘 해내고 싶은 행동은 무엇인가요?” 올해 기존 목표를 추가로 적을 수 있으나 소프트 삭제되지 않은 올해 목표는 상태와 관계없이 최대 3개다. 한도 도달 시 추가 입력을 막고 현재 개수와 가능한 조치를 안내한다. ‘올해 남은 기간’은 안내 표현이며 연간 목표 기간은 1월 1일~12월 31일로 고정한다. 가입 전 행동 이력은 추정하지 않으며, 기존 달성 여부 반영은 기준·배점 확정 시 사용자가 선택적으로 확인한 항목에 한한다. | 필수 |
| PLAN-003 | 사용자는 1월 1일에만 계획을 시작할 필요 없이 연중 언제든 올해 목표를 정리할 수 있다. 첫 방문 온보딩의 목표→이번 달 목표→이번 주 결과→오늘 행동 순서는 계획 수립의 한 경로다. 월초에는 올해 목표를 보며 이번 달 목표와 실행 계획을 수립하고, 월말에는 해당 월의 실제 실행 결과 리포트를 조회한다. 주초에는 이번 달 목표와 직전 주의 실제 진행(완료한 일과 남은 일)을 함께 확인한 뒤, 사용자가 다음 단계로 무엇을 할지 선택해 이번 주 목표와 계획을 수립한다. 첫 주처럼 직전 주 기록이 없어도 이번 달 목표를 바탕으로 계획을 세울 수 있다. 하루를 시작할 때는 주간 목표를 보며 오늘의 핵심 행동을 정한다. | 필수 |
| PLAN-004 | 계정 시간대의 기본값은 `Asia/Seoul`이며 사용자가 설정에서 변경할 수 있어야 한다. 오늘·주간 경계·기한 남은 일수·리포트 기간은 해당 시간대로 판정한다. 일정의 날짜·기한과 행동의 실제 수행일은 구분해 저장한다. | 필수 |

### 아침 사분면

매일 사용자는 오늘 할 일의 중요도(x)와 긴급도(y)를 각각 0~100으로 직접 분류할 수 있다. 연간·월간 목표 경로를 통해 등록한 오늘 행동은 중요도가 높은 절반(x >= 50)에만 둘 수 있고, 긴급도(y)는 높거나 낮게 자유롭게 정한다. `그 밖의 할 일`(Maintenance)은 네 사분면 어디에나 둘 수 있다. 사용자는 분류를 언제든 다시 열어 수정할 수 있다. 분류는 해당 날의 판단을 돕는 표시값으로 기록하며, 저장된 행동 순서나 목표 진행률·집중 성과를 바꾸지 않는다. 오늘 목록은 사용자가 고른 표시 정렬에서 중요도·긴급도 좌표를 기준으로 재배치할 수 있다. 기본 행동 기록은 분류 전에도 가능하다.

확장판에서 AI 추천을 요청하면 항목마다 중요도 x와 긴급도 y를 각각 0~100 좌표로 제안하고 짧은 추천 이유를 제공한다. 목표 연결, 기한, 사용자가 제공한 필요 준비 시간을 참고하되 정보가 부족하면 단정하지 않고 불확실성을 드러낸다. 목표 경로의 행동은 AI 추천 및 사용자가 최종 승인하는 좌표 모두 x >= 50이어야 하며, 긴급도는 제한하지 않는다. `그 밖의 할 일`(Maintenance)에는 네 사분면 좌표를 모두 추천할 수 있다. 추천 좌표는 사분면 화면의 점 위치로 표시하며, 사용자는 점을 드래그하거나 값을 수정한 뒤 최종 승인한다. BYOK 또는 유효한 AI 서비스 결제 자격이 있는 사용자에게 향후 제공하며, 제출판은 `해당 기능은 현재 개발 중입니다.` 안내만 표시한다. 직접 분류는 모든 사용자에게 유지한다.

각 연간 목표에는 사용자가 정의한 달성 기준을 둘 수 있다. 첫 방문 온보딩에서 기준·배점 확정을 강제하지 않으며, 기준이 확정되지 않은 동안 연간 진행률 대신 `달성 기준 설정하기`(또는 설정 전 상태)를 표시한다. 사용자는 언제든 기준과 배점을 정리해 확정할 수 있고 확정 시 배점 합계는 100점이어야 한다. 확정 후에도 기준과 배점을 개정할 수 있다. 확정할 때 기본 진행률 0%를 최초 기준선으로 저장하며, 사용자가 선택적으로 이미 달성한 기준을 확인하면 해당 기준의 배점을 반영해 최초 기준선을 저장한다. 이후 변화만 기록 시작 이후 변화로 리포트에 표시하고, 가입 전 행동 이력은 추정하지 않는다. 기준 달성 확인은 해당 배점을 한 번 반영하고 취소 시 차감한다. 이 기준 기반 진행률은 실제 수행한 행동 기록과 분리한다. 여러 연간 목표는 각각 독립된 기준과 진행률을 가진다.

요청 실패나 연결 해제 상태에서도 수동 계획·기록 기능은 정상 동작해야 한다. AI 자격은 기능 제공 시 서버가 확인한다. 유효한 BYOK 자격과 유효한 AI 서비스 결제 자격이 모두 없으면 AI 요청을 허용하지 않고, 기본 수동 기능과 실제 제공 중인 연결 또는 결제 안내를 제공한다. 승인 전 AI는 자동 저장·수정·삭제 또는 달성 처리하지 않는다. BYOK 키의 영구 보관 방식과 상세 추천 알고리즘은 미정이다.

제출판의 AI·BYOK·서비스 결제·외부 AI 에이전트 플러그인/MCP는 모두 확장 범위다. 제출판 웹의 관련 AI·BYOK·결제·플러그인/MCP 진입점에는 `해당 기능은 현재 개발 중입니다.`를 표시한다. 제출판에서는 API 키 입력, 결제, AI 또는 외부 에이전트의 실제 호출·연동을 제공하지 않는다. 출시 후 Aim2Day 웹의 AI 기능(계획, 배점 추천, 관련성 점검, 회고 초안 등)은 유효한 BYOK 자격 또는 유효한 AI 서비스 결제 자격 중 하나를 서버에서 확인한 경우 제공한다. 둘 다 없는 경우 AI 요청은 허용하지 않고 기본 수동 기능과 실제 제공 중인 연결 또는 결제 안내를 제공한다. 외부 AI 에이전트가 Aim2Day에 연동되는 플러그인/MCP는 향후 BYOK 사용자 지원을 우선 검토하며, 결제 자격 사용자 지원 여부는 미정이다. 모바일 앱도 확장 검토 후보로 둔다.

사용자 간 공유 컨설팅은 미정 검토 후보로, 초대받은 사람이 목표에 피드백을 제공하고 원소유자가 반영 여부를 결정하는 형태를 검토할 수 있다. 일반 소셜 기능인 팔로우는 제공 범위에서 제외한다.

## 제출판 시연 및 수용 범위

제출판 시연은 구현된 핵심 수동 기능과 분산 처리·데이터 보존을 대상으로 한다. 제출판에서 확장으로 분류한 AI·BYOK·결제·플러그인/MCP는 실제 동작을 시연하거나 수용 판정하지 않으며, 웹 관련 진입점에는 `해당 기능은 현재 개발 중입니다.`를 표시한다. 확장 구현 후에는 별도 확장 검증에서 실제 자격 판정, 안전한 호출, 사용자 승인 및 실패 시 수동 기능 유지 여부를 확인한다.

교수님 개인 SMTP 키를 요구하지 않도록, 로컬 테스트 수신함 등으로 인증 및 비밀번호 재설정 메일의 링크를 확인하는 시연 방식을 검토한다. 로컬 테스트 수신함의 구체적인 구성은 구현 환경에 맞춰 정한다.

시연은 미리 인증을 마친 정상 데모 계정으로 수행한다. 제출물에는 설정과 실행 명령을 포함해 역방향 프록시 경로와 세 목표 서비스 인스턴스 분산을 재현할 수 있어야 한다.

## 7. 수용 기준

1. 연간 목표→월간 목표→주간 목표를 연결하고, 같은 사용자·달력연도의 소프트 삭제되지 않은 연간 목표를 상태와 관계없이 최대 3개까지만 보유할 수 있다. 한도 도달 시 생성을 차단하고 명확한 안내를 표시하며 소프트 삭제는 개수에서 제외하고 복원 시 한도를 재검사한다. 이 제한은 월간·주간·일일 항목 개수에는 적용하지 않으며, 매일 주간 목표에 연결한 행동은 제한 없이 추가할 수 있다.
2. 목표에 연결한 일정과 `Maintenance`를 작성하고 각각 완료 처리할 수 있다. 오늘 행동에는 우선순위를 강제하지 않으며, 연간 목표의 순서는 사용자가 편집할 수 있다.
3. 완료 기록이 연결된 주간 목표와 월간 목표의 진행 집계에 반영된다.
4. 사용자 정의 연간 달성 기준과 실제 행동 기록이 분리되어 집계된다.
5. 월 경계 주간 목표는 겹치는 월간 목표 중 하나에 연결되고, 행동은 실제 수행 월에 한 번 집계된다.
6. 회원가입 시 입력한 이메일 주소로 인증 링크를 받아 만료 전에 한 번만 사용할 수 있다.
7. 비밀번호 재설정 링크는 만료 전에 한 번만 사용할 수 있으며, 재설정 완료 후 이전 비밀번호는 거부된다.
8. 분산 처리와 데이터 보존을 각각 확인한다.
   - 한 번 로그인한 뒤 같은 사용자의 목표를 다른 목표 서비스 인스턴스에서 재로그인 없이 조회할 수 있다.
   - MySQL 컨테이너를 다시 만들더라도 같은 영속 볼륨을 사용하면 저장한 목표가 남아 있다.
9. 제출판에서는 BYOK 키 입력이나 AI 호출 없이 기본 수동 기능을 사용할 수 있고, 관련 AI·BYOK·결제·플러그인/MCP 진입점에 개발 중 안내가 표시된다. 주 시작 요일은 기본 일요일이며, 사용자가 바꾸면 주간 계획·오늘·달력에 일관되게 적용된다.
10. 월초·주초 계획과 월·분기·연말 기본 리포트는 실제 기록을 기준으로 하며, `Maintenance`를 제외하고 기록되지 않은 행동·활동일·결과·시간을 추정하지 않는다. 지연된 항목은 종료일이 지나도 완료 처리 전까지 진행 중 상태로 남는다. 월간 목표 생성은 항상 현재 달을 대상으로 하며 대상 월 입력란이 없다. 연간·월간·주간 목표는 수정·소프트 삭제·복원할 수 있다. 상위 목표를 삭제하면 하위 목표와 연결된 미완료 행동이 숨고, 복원하면 다시 나타난다.
11. 연중 가입·새해 계획, 월 경계 주간 계획, 월·분기·연말 회고를 제공하며, 연말 경계 주간의 목표 귀속과 실제 행동 집계를 연도별로 검증할 수 있다.
12. 제출 설정과 실행 명령으로 프록시 경로와 세 목표 인스턴스 분산을 재현하고, 시연은 사전 인증된 정상 데모 계정으로 수행한다.
13. 제출판에서 AI 기능은 개발 중 안내만 표시하며 API 키 입력·결제·실제 AI 호출을 제공하지 않는다. 확장 검증 시에는 BYOK 또는 유효한 AI 서비스 결제 자격 중 하나를 서버에서 확인한 뒤 AI 제안을 후보로 제시하고, 사용자 승인 전 저장·변경·삭제·달성 처리하지 않는다. 자격이 없거나 AI 요청이 실패해도 수동 기능을 계속 사용할 수 있다.
14. 연말 경계의 2026-12-26~2027-01-01 주간 목표는 겹치는 2026년 12월 또는 2027년 1월 목표 중 하나에만 연결하고, 2026년 12월 30일과 2027년 1월 1일 행동은 각 수행일의 달력연도·월 회고에 한 번씩만 집계한다.
15. 기준이 확정된 목표는 월·분기·연간 기본 리포트에 기간 시작 대비 말의 목표별 달성 기준 진행률 변화(%p)가 표시된다. 최초 기준선 확정 전에는 퍼센트 변화 대신 기준 설정 전 상태를 표시한다. 기준·배점 변경 또는 관측 없음으로 비교가 불가능하면 실적 변화로 오인되지 않게 이를 명시한다.
16. 제출판에서 AI 회고는 개발 중 안내만 표시하고 키 입력·결제·실제 호출을 제공하지 않는다. 확장 검증 시 AI 서술형 회고 초안은 유효한 BYOK 자격 또는 제공 중인 AI 서비스 결제 자격 중 하나를 서버에서 확인한 사용자에게만 허용하며, 사용자는 초안을 수정하고 승인할 수 있다. 자격이 없는 사용자에게는 완전한 기본 리포트와 직접 회고를 제공하고, AI 회고 선택 시 실제 제공 중인 수단만 안내한다.
17. 체크형 주간 목표는 연결 행동의 완료 비율로 계산한다. 수치형 주간 목표는 연결 행동에 기록한 기여량을 완료 시 실제값에 반영하고 완료 취소 시 되돌린다. 예를 들어 10문제 목표에 2문제 행동을 완료하면 2를 더한다. 직접 입력은 이번에 추가한 양으로 저장하고 출처를 구분하며, 같은 행동 완료 요청을 반복해도 한 번만 반영한다. 실제값이 14문제여도 막대는 100%에서 멈추고 완료 색상으로 표시하며 실제값 14는 보존한다. 월간 진행률은 기록 없는 하위 주간 목표도 0%로 포함해 가중 평균으로 계산하고 소수점 둘째 자리까지 반올림한다.
18. 행동 수행일은 기본 오늘로 지정되며 수정할 수 있다. 예를 들어 어제 수행한 행동을 오늘 입력해도 어제 날짜로 기록하면 어제의 리포트에 집계된다.
19. 온보딩에서 연간 기준·배점 확정을 강제하지 않으며, 확정 전에는 진행률 대신 `달성 기준 설정하기`(또는 설정 전 상태)를 표시한다. 기준·배점 합계 100점을 확정하면 기본 0%를 최초 기준선으로 저장하고, 사용자가 선택적으로 이미 달성한 기준을 표시하면 해당 배점을 최초 기준선에 반영한다. 예를 들어 최초 기준선이 20%이고 이후 35%가 되면 +15%p를 기록 시작 이후 변화로 표시한다. 가입 전 행동 이력은 추정하지 않는다.
20. 상위 목표를 삭제하거나 보류하면 그 아래 미완료 행동은 오늘 목록에서 숨긴다. 이미 실제 수행한 행동 기록은 당시 리포트에 남는다.
21. 첫 방문 온보딩은 네 질문만 순서대로 한 경로에서 제시하고, 올해 목표부터 이번 달 목표·이번 주 결과·오늘 행동까지 이어 작성할 수 있다. 작성 도중 이탈해도 입력 내용을 임시 저장하고 다음 방문에 이어 쓴다. 온보딩은 연간 달성 기준·배점 확정을 요구하지 않는다. 올해 기존 목표도 입력할 수 있으며, 같은 달력연도에 소프트 삭제되지 않은 연간 목표가 최대 3개임을 적용한다. 진행·완료·보류·중단 상태는 한도 계산에서 동일하게 취급하고, 소프트 삭제 목표는 제외하며 복원 시 재검사한다. 생성 또는 복원이 한도를 넘기면 차단하고 현재 개수·최대 개수와 가능한 조치를 안내한다. 연간 목표 기간은 1월 1일~12월 31일로 유지된다.
22. 대시보드에는 월 달력이 포함되지 않는다. 본문은 오늘 계획→`해야 할 일 | 일정` 두 열→이번 주 계획→이번 달 계획 순서다. 기한이 지난 `해야 할 일`도 완료 전까지 모두 표시한다. 일정은 오늘부터 7일 이내와 진행 중인 기간 일정만 기본으로 보여주고, 최근 7일 이내에 끝난 일정은 접힌 `지난 일정`에서 본다. 좁은 화면에서는 두 열을 세로로 쌓는다. 연간 목표는 별도 메뉴에서 관리한다.
23. 달력은 독립 메뉴로 접근할 수 있고 `오늘` 바로가기는 현재 날짜를 선택한다. `해야 할 일`은 마감일 칸에, 하루 일정은 해당 날짜 칸에, 기간 일정은 시작일부터 종료일까지 표시한다. 날짜 칸의 칩이나 빈 공간을 누르면 해당 날짜를 선택하고 아래 선택 날짜 목록으로 이동한다. 두 종류 모두 생성·수정·완료 처리가 가능하며, 목표 연결 항목은 목표 이름과 색상으로 표시되고 목표별 필터가 작동한다. 행동의 실제 수행일은 달력 항목과 별도로 기록해 리포트에 사용한다.
24. 연간 목표 메뉴는 올해의 유효 목표를 카드로 표시한다. 기준·배점 미확정 목표는 퍼센트 진행률 대신 `달성 기준 설정하기`(또는 설정 전 상태)를 표시한다. 가용 폭이 충분하면 가로로, 부족하면 세로로 배치한다. 각 카드에서 해당 목표 상세를 열 수 있고, 사용자가 편집해 저장한 전체 카드 순서는 재방문 후에도 유지된다. 목표 상세에는 진행률 또는 기준 설정 전 상태, 달성 기준과 하위 목표가 보인다.
25. 대시보드 어디에도 올해·이번 달의 시간 경과 막대, 날짜 경과율 또는 이를 계산한 대체 지표를 표시하지 않는다.
26. 사분면 AI 확장 검증 시 항목별 중요도 x·긴급도 y의 0~100 좌표와 추천 이유를 제안하고, 점 드래그·값 수정 후 사용자가 승인해야 반영한다. 목표 경로 행동의 추천 및 승인 좌표는 x >= 50으로 제한하고 y는 제한하지 않으며, `그 밖의 할 일`은 네 사분면을 모두 허용한다. 좌표는 해당 날의 판단 표시값이며 강제 순서나 진행률에 반영되지 않는다. 정보 부족을 단정하지 않고, BYOK 또는 유효한 AI 서비스 결제 자격을 서버에서 확인한다.

27. 오늘 분류에서 연간·월간 목표 경로의 행동은 중요도 x >= 50에만 배치할 수 있고 긴급도 y는 높음·낮음 모두 가능하다. 그 밖의 할 일(Maintenance)은 네 사분면 어디든 배치할 수 있다. 재분류에도 같은 제약을 적용하며, 분류 변경은 저장된 행동 순서·진행률·집중 성과에 영향을 주지 않는다. 화면 정렬이 좌표를 사용하는 경우에는 사용자가 고른 표시 순서만 달라진다.

28. 로그인 상태의 상단 내비게이션에는 날짜 대신 회원명과 로그아웃이 표시되고, 로그아웃하면 세션이 무효화된 뒤 로그인과 회원가입이 표시된다. 비로그인 상태로 처음 접근한 경우에도 로그인과 회원가입이 표시된다.

29. 오늘 목록의 기본 `중요도+긴급도` 정렬은 좌표 합계 내림차순, 동점이면 중요도 내림차순, 다시 동점이면 기존 입력 순서로 표시된다. 미분류 점은 좌표 평면 밖의 대기 영역에 있고 목록 행에는 점이 표시되지 않는다. 점을 좌표 평면에 놓으면 목록에 미확정 좌표가 표시되며, 점의 행동 제목은 포인터 올림·포커스·선택·드래그 중 점 아래에 표시된다.

### 오늘 할 일 프로토타입 규칙

오늘 목록은 목표 연결 행동과 그 밖의 할 일의 완료 수를 별도 요약으로 표시한다. 기본 표시에서는 두 종류를 배지로 구분한 단일 목록을 사용하며, 사용자는 두 그룹으로 나눠 보는 표시 정렬을 선택할 수 있다. 그 밖의 할 일 완료는 목표 진행률에 포함하지 않는다. 완료 처리는 중요도·긴급도 분류보다 먼저 할 수 있으며, 분류 영역은 접고 펼칠 수 있고 미분류 수와 빈 상태를 보여준다. 달력은 `해야 할 일`의 마감일과 일반 일정의 해당 날짜를 표시한다. 행동의 수행일은 실제 완료 기록과 리포트에 사용한다. 기한을 지정하지 않은 행동에는 남은 일수를 표시하지 않는다.

분류 영역은 하루 첫 진입 때 오늘 할 일을 돌아보도록 가볍게 안내할 수 있다. 안내는 화면 안의 비차단 문구로 제공하고 완료 처리보다 분류를 우선 요구하지 않는다. 그날 분류를 확정한 뒤에는 같은 날에 안내를 두드러지게 반복하지 않는다.

사분면 분류는 좌표 영역 위쪽·바깥에 놓인 미분류 대기 트레이의 작은 점을 사분면 안으로 드래그하거나, 점을 선택한 뒤 키보드 방향키로 옮겨 수행한다. 오늘 할 일 행에는 완료 체크만 두며 별도의 드래그 점 핸들을 두지 않는다. 트레이의 미분류 점은 사분면 좌표를 갖지 않으며, 사분면 안에 놓인 좌표는 사용자가 아직 확정하지 않은 `미확정` 상태로 표시한다. 사용자가 분류를 확정하면 배치된 점만 해당 날짜 분류로 저장되고 사분면에 남는다. 트레이에 남은 점은 분류되지 않은 상태로 유지한다. 점에 포인터를 올리거나 포커스·선택·드래그하면 행동 제목을 점 바로 아래에 표시하고, 전체 제목과 목표 경로 및 좌표 상태를 확인할 수 있어야 한다.

오늘 행동 목록은 정렬 선택에 따라 `목표 / 그 밖의 할 일`, `중요도+긴급도`, `중요도 높은 순`, `긴급도 높은 순`으로 볼 수 있다. `중요도+긴급도`는 좌표 합계 내림차순으로 정렬하고 합계가 같으면 중요도 내림차순, 중요도도 같으면 기존 입력 순서를 적용한다. 좌표 정렬에서는 미분류 항목을 분류된 항목 뒤에 둔다. 분류되지 않은 점은 사분면 위쪽·바깥의 대기 트레이에 두며, 트레이에서 사분면으로 드래그해 배치한다. 사분면 안의 작은 점은 키보드 조작도 지원한다. 이 정렬은 화면 표시 순서만 바꾸며 목표 진행률·행동의 우선순위 저장을 뜻하지 않는다.
