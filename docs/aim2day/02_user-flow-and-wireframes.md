# Aim2Day 화면 흐름과 저충실도 와이어프레임

> 과제 제출판 화면 구조 초안. 상자 안의 위치와 정보, 사용자가 할 수 있는 동작을 정리한다. 색상·장식·세부 시각 디자인은 다루지 않는다.

## 화면 흐름

### 첫 방문

```text
가입·로그인
    ↓
올해 목표가 있나요?
    ├─ 없음 → 올해 목표 작성
    └─ 있음 → 기존 올해 목표 작성
                    ↓
             이번 달 목표 작성
                    ↓
             이번 주 목표 작성
                    ↓
             오늘 행동 작성
                    ↓
                대시보드
```

### 다시 방문

```text
로그인 → 올해 목표 한도 확인
           ├─ 올해 목표가 없거나 온보딩을 이어야 함 → 온보딩
           └─ 올해 목표 있음 → 대시보드
           ├─ 오늘 행동 기록·완료
           ├─ 목표를 눌러 월간·주간 계획 보기
           ├─ 그 밖의 할 일 기록
           └─ 기간이 끝나면 리포트 보기
```

비회원은 로그인 화면에서 회원가입으로 이동할 수 있다. 첫 방문 회원은 온보딩을 마치면 대시보드로 이동한다. 상단의 주요 메뉴에는 대시보드, 달력, 연간 목표, 리포트를 두고, 로그인한 회원의 계정 영역에는 로그아웃 바로 옆에 설정을 둔다. 연간 목표 메뉴의 카드에서 목표별 상세를 열고, 달력 메뉴에서는 날짜별 일정을 관리한다.

## 첫 방문 네 질문

온보딩은 연간 목표·이번 달 목표·이번 주 결과·오늘 행동의 네 질문만으로 이루어진 하나의 순차 경로다. 각 질문에서 입력한 항목은 바로 위 단계에 연결한다. 연간 달성 기준이나 배점 확정은 온보딩에서 요구하지 않는다. 같은 달력연도에 소프트 삭제되지 않은 연간 목표는 진행·완료·보류·중단 상태를 합쳐 최대 3개다. 첫 질문에서 기존 목표를 포함해 남은 수만 입력할 수 있고, 한도에 도달하면 추가 입력을 막고 현재 개수·최대 개수와 기존 목표를 정리할 수 있다는 안내를 표시한다. 소프트 삭제된 목표는 한도에서 제외하지만 복원할 때 한도를 다시 검사한다. 월간·주간·일일 항목 개수는 제한하지 않는다. 연간 목표 기간은 1월 1일부터 12월 31일까지다.

```text
+------------------------------------------------------------------+
| Aim2Day                                        첫 방문 계획 1 / 4  |
+------------------------------------------------------------------+
|                                                                  |
|  올해 어떤 일에 집중하고 싶나요?                                     |
|                                                                  |
|  [ 연간 목표 제목                                           ]      |
|  [ + 연간 목표 추가 ]   (최대 3개, 현재 1개)                       |
|  한도에 도달하면 추가할 수 없습니다. 목표를 정리한 뒤 다시 시도하세요. |
|                                                                  |
|  연간 목표: 2026년                                                 |
|  기존 목표 포함 최대 3개. 진행·완료·보류·중단 목표를 모두 셉니다.     |
|                                                                  |
|                         [다음: 이번 달 목표]                       |
+------------------------------------------------------------------+
```

```text
+------------------------------------------------------------------+
| Aim2Day                                        첫 방문 계획 2 / 4  |
+------------------------------------------------------------------+
|  그 목표를 위해 이번 달에 이루고 싶은 건 무엇인가요?                    |
|                                                                  |
|  연결할 연간 목표 [ 목표 선택                              v ]      |
|  이번 달에 이루고 싶은 것 [                                  ]      |
|  설명 / 기대 결과          [                                  ]    |
|                                                                  |
|  기간: 선택된 달력 월                                               |
|               [이전]                    [다음: 이번 주 결과]        |
+------------------------------------------------------------------+
```

```text
+------------------------------------------------------------------+
| Aim2Day                                        첫 방문 계획 3 / 4  |
+------------------------------------------------------------------+
|  이번 주에는 어떤 결과를 만들고 싶나요?                          |
|                                                                  |
|  연결할 월간 목표 [ 목표 선택                              v ]   |
|  이번 주 결과             [                                  ]   |
|  측정 방식                (•) 체크리스트  ( ) 수치형             |
|  수치형일 때 목표값       [              ]                       |
|                                                                  |
|  주간 목표는 한 월간 목표에 연결됩니다.                           |
|               [이전]                    [다음: 오늘 행동]         |
+------------------------------------------------------------------+
```

```text
+------------------------------------------------------------------+
| Aim2Day                                        첫 방문 계획 4 / 4  |
+------------------------------------------------------------------+
|  그러면 오늘 해내고 싶은 행동은 무엇인가요?                      |
|                                                                  |
|  먼저 선택       (•) 이번 달 목표  ( ) 그 밖의 할 일             |
|  이번 달 목표    [ 목표 선택                              v ]   |
|  연결할 주간 목표 [ 해당 월간 목표에 주간 목표가 여러 개면 선택 v ]|
|  행동                     [                                  ]   |
|  수행일                   [ 오늘: YYYY.MM.DD              v ]   |
|  [ + 행동 추가 ]                                                 |
|                                                                  |
|  연결된 주간 목표가 하나면 자동 연결하고, 여러 개면 선택합니다.   |
|  그 밖의 할 일은 목표 경로 없이 저장됩니다.                      |
|               [이전]                    [계획 완료]              |
+------------------------------------------------------------------+
```

첫 번째 질문은 1월에 `올해 어떤 일에 집중하고 싶나요?`, 2~12월에 `올해 남은 기간에 어떤 일에 집중하고 싶나요?`로 표시한다. 두 번째 질문은 모든 달에 `그 목표를 위해 이번 달에 이루고 싶은 건 무엇인가요?`로 표시하며, 세 번째와 네 번째 질문은 명세 문구 그대로 사용한다. 날짜와 주 시작 요일에 따라 이번 달·이번 주 기간을 표시한다. 연간 달성 기준과 배점은 온보딩 질문에 추가하지 않으며, 완료 후 연간 목표 상세의 `[기준 관리]`에서 별도로 설정한다.

## 로그인

```text
+------------------------------------------------------------------+
| Aim2Day                                                           |
+------------------------------------------------------------------+
|                         로그인                                    |
|                                                                  |
|  이메일 [                                                  ]   |
|  비밀번호             [                                      ]   |
|                                                                  |
|  [로그인]                                                        |
|  회원가입                                      비밀번호 재설정    |
+------------------------------------------------------------------+
```

로그인 성공 후 올해 목표가 없으면 네 질문 온보딩으로, 올해 목표가 있으면 대시보드로 이동한다. 올해 목표 존재 여부와 개수는 진행·완료·보류·중단 상태를 합산하고 소프트 삭제 목표는 제외해 판단한다. 이메일 인증을 마치지 않은 계정은 로그인할 수 없으며, 로그인 화면에 `이메일 인증 후 로그인할 수 있습니다.`와 `[인증 메일 다시 보내기]`를 표시한다. 회원가입과 비밀번호 재설정은 제출판 인증 절차를 제공한다.

## 회원가입

```text
+------------------------------------------------------------------+
| Aim2Day                                                           |
+------------------------------------------------------------------+
|                         회원가입                                  |
|                                                                  |
|  이메일          [                                          ]    |
|                  로그인과 인증 메일 수신에 사용합니다.            |
|  사용자명        [                                          ]    |
|                  화면에 표시되는 이름입니다. 다른 사람과 같아도 됩니다. |
|  비밀번호        [                                          ]    |
|  비밀번호 확인   [                                          ]    |
|                                                                  |
|  [가입하기]                                                      |
|  이미 계정이 있나요? 로그인                                      |
+------------------------------------------------------------------+
```

```text
+------------------------------------------------------------------+
| Aim2Day                                                           |
+------------------------------------------------------------------+
|                    인증 메일을 보냈습니다                         |
|                                                                  |
|  user@example.com 으로 보낸 링크를 열어 인증을 마쳐 주세요.       |
|  링크는 일정 시간이 지나면 만료되며 한 번만 사용할 수 있습니다.   |
|  인증을 마쳐야 로그인할 수 있습니다.                             |
|                                                                  |
|  [인증 메일 다시 보내기]                      [로그인으로 이동]   |
+------------------------------------------------------------------+
```

가입 시 이메일 형식, 이미 가입된 이메일, 비어 있는 사용자명, 비밀번호와 비밀번호 확인의 불일치를 입력란 아래에 안내한다. 이메일은 계정마다 하나만 쓸 수 있고 사용자명은 중복을 허용한다. 가입 요청이 성공하면 인증 메일 안내 화면으로 이동한다. 메일 전송에 실패하면 가입이 끝난 것처럼 보이지 않게 실패를 알리고 `[인증 메일 다시 보내기]`를 제공한다. 메일의 인증 링크를 열면 결과 화면에서 인증 완료 또는 만료·이미 사용한 링크임을 알리고 로그인으로 이동할 수 있게 한다. 비밀번호 규칙(길이 등)은 API 설계에서 정한다.

## 대시보드

```text
+------------------------------------------------------------------+
| Aim2Day [대시보드] [달력] [연간 목표] [리포트]   [로그아웃] [설정] |
+------------------------------------------------------------------+
| 오늘 행동                                       [+ 행동 추가]     |
| [ ] 목표 연결 행동 — 목표 경로                                  |
| [ ] 그 밖의 할 일                                                |
+------------------------------------------------------------------+
| 해야 할 일                          | 일정                       |
| [ ] 과제 제출 — D-2               | [ ] 발표 — 내일             |
| [ ] 장학금 신청 — 기한 지남        | [ ] 여행 — 진행 중          |
| 완료 전 모든 항목                   | 오늘~7일 이내 + 진행 중     |
|                                    | ▸ 지난 일정 · 최근 7일      |
+------------------------------------------------------------------+
| 이번 주 계획                                                      |
| 주간 목표 — 연간 목표 > 월간 목표 — 진행률 — [상세]               |
| [이번 주 목표 설정]                                               |
| 주간 목표와 연결된 일정 요약                                      |
+------------------------------------------------------------------+
| 이번 달 계획                                                      |
| 월간 목표 — 연간 목표 — 진행률 — [상세]                           |
| 다음 단계와 주요 일정 요약                                        |
| [이번 달 목표 설정]                                               |
+------------------------------------------------------------------+
| 최근 진행 기록: 날짜 · 변경 항목 · 메모                           |
+------------------------------------------------------------------+
```

대시보드 본문은 오늘 행동→`해야 할 일 | 일정` 두 열→주→월 순서다. 좁은 화면에서는 두 열을 세로로 쌓는다. `해야 할 일`은 완료 전까지 기한과 관계없이 모두 보여 주고, 완료하면 미완료 목록에서 내려간다. `일정`은 오늘부터 7일 이내의 항목과 현재 진행 중인 기간 항목을 보여 준다. 최근 7일 이내에 끝난 일정은 접힌 `지난 일정`에서 종료일 기준 `D+1`처럼 표시하고, 그보다 오래된 것은 달력에서 조회한다. 두 종류 모두 완료 체크를 제공하며, 날짜와 남은 일수는 계정 시간대를 따른다(기한 당일은 `오늘`, 기한이 지난 `해야 할 일`은 `기한 지남`). 사용자는 이를 참고해 이번 주 목표와 오늘 행동을 계획한다. 목표 연결 항목은 목표 이름과 색상으로 표시한다. `[이번 달 목표 설정]`과 `[이번 주 목표 설정]`은 월간·주간 목표 설정 화면으로 이동한다. 연간 목표 카드나 시간 경과 지표는 표시하지 않는다. 연간 목표 생성·수·상태 규칙은 연간 목표 메뉴에서 적용한다.

### 월간·주간 목표 설정

```text
+------------------------------------------------------------------+
| [대시보드] > 월간·주간 목표 설정                                  |
+------------------------------------------------------------------+
| 큰 목표에서 이번 달의 결과를 정하고, 그 결과를 이번 주 목표로 구체화 |
+------------------------------------------------------------------+
| 이번 달 목표 만들기                                               |
| 연결할 올해 목표 [목표 선택 v]                                    |
| 이번 달에 이루고 싶은 결과 [                                  ]   |
| [월간 목표 저장]                                                  |
+------------------------------------------------------------------+
| 이번 주 목표 만들기                                               |
| 연결할 이번 달 목표 [목표 선택 v]                                 |
| 이번 주에 이루고 싶은 결과 [                                  ]  |
| 측정 방식 [수치형 v / 행동 체크형]                                |
| 목표 수치 [          ] (수치형 선택 시)                           |
| [주간 목표 저장]                                                  |
+------------------------------------------------------------------+
| 설정한 목표                                                       |
| 연간 목표 › 월간 목표                         [수정] [삭제]       |
|   연간 목표 › 월간 목표 › 주간 목표           [수정] [삭제]       |
+------------------------------------------------------------------+
```

대시보드의 두 설정 버튼은 같은 설정 화면으로 이동한다. 월간 목표는 연간 목표를 부모로 선택하고 현재 달의 결과를 입력한다. 대상 월은 현재 달로 자동 결정되며 선택하거나 입력하는 항목이 없다. 주간 목표는 월간 목표를 부모로 선택하고 이번 주 결과와 측정 방식을 정한다. 수치형이면 목표 수치를 입력하며, 행동 체크형이면 핵심 행동 완료 여부로 진행을 기록한다. 월간 목표를 먼저 저장해야 그 목표를 주간 부모로 선택할 수 있다. 정적 시안에 표시된 목표명·수치는 화면 흐름 예시이며 사용자의 실제 목표나 기록을 뜻하지 않는다.

## 달력

```text
+------------------------------------------------------------------+
| Aim2Day [대시보드] [달력] [연간 목표] [리포트]   [로그아웃] [설정] |
+------------------------------------------------------------------+
| 달력     [< 이전] [오늘] [다음 >]       [월 v] [2026년 11월 v]   |
| 목표 필터 [전체 v]   [ ] 목표 A   [ ] 목표 B   [ ] 그 밖의 할 일  |
+------------------------------------------------------------------+
| 일      월      화      수      목      금      토                |
| [1]     [2]     [3]     [4]     [5]     [6]     [7]               |
| [일정 A]        [일정 B] [완료 일정: 옅게, 색 막대 없음]           |
| [8]     [9]     [10]    [11]    [12]    [13]    [14]              |
| [목표별 색상 칩] [그 밖의 할 일 칩]                               |
+------------------------------------------------------------------+
| 선택 날짜: YYYY.MM.DD       [+ 일정 만들기]                       |
| 일정 이름 — 목표 이름/색상 — 마감일 — 상태 [완료]                 |
+------------------------------------------------------------------+
```

`오늘`은 현재 날짜로 즉시 이동한다. 주 표시와 날짜 경계는 사용자 설정을 따르며 초기 설정은 일요일 시작이다. 월간 달력은 날짜마다 독립된 칸을 사용한다. **해야 할 일**은 마감일 칸에, 하루 일정은 해당 날짜 칸에, 기간 일정은 시작일부터 종료일까지 목표 색상의 작은 칩으로 표시한다. 날짜 칸 안의 칩이나 빈 공간을 누르면 해당 날짜를 선택하고 아래 선택 날짜 목록으로 이동한다. 완료한 항목은 칩과 목록에서 옅게 표시하고 왼쪽 색상 막대를 제거한다. 사용자는 종류를 선택해 달력 항목을 생성·수정·완료 처리할 수 있다. 목표 필터에서 목표별 항목을 선택하거나 숨길 수 있고, 목표 미연결 `Maintenance` 항목도 별도 선택할 수 있다. 목표 이름과 색상은 해당 목표 설정을 따른다. 목표 행동의 실제 수행일은 달력 항목과 분리해 리포트에 사용한다.

목표 카드는 가용 폭이 충분하면 가로로 나열하고, 좁은 화면에서는 세로로 쌓는다. `[상세]`를 누르면 해당 목표 상세를 연다. 순서 편집은 목록 전체를 재배치하고 저장하며, 다음 방문에도 같은 순서를 유지한다. 연간 목표 카드와 상세에서, 월간·주간 목표는 설정 목록에서 수정·삭제를 제공하고, 소프트 삭제된 목표는 `[삭제된 목표 보기]`에서 복원할 수 있다. 연간 목표는 최대 3개이며, 한도에 도달하면 추가와 한도 초과 복원을 막고 현재 개수·최대 개수와 가능한 조치를 안내한다. 각 목표 이름과 색상은 목표별 설정에서 변경한다. 상위 목표 삭제 시 확인 창을 거쳐 하위 목표와 그 경로의 미완료 핵심 행동을 숨기며, 상위 목표를 복원하면 원래 연결을 유지한 채 다시 표시한다. 완료된 행동 기록은 삭제하지 않는다.

## 목표 상세 및 월·주 계획

삭제된 목표 목록에서는 목표 단계와 관계없이 삭제 시각부터 30일 이내에 복원 가능한 항목과 남은 기간을 표시한다. 복원 동작은 해당 연간 목표의 개수 한도 검사를 포함한다. 삭제 확인 화면에는 30일 뒤 앞으로의 계획과 미완료 행동은 영구 삭제되고, 완료한 목표·행동과 달성한 기준은 과거 이력으로 남는다고 안내한다. 복구 기간이 끝난 계획은 복원할 수 없으며 과거 이력은 새 목표나 행동의 부모로 선택할 수 없다.

```text
+------------------------------------------------------------------+
| 삭제된 목표                                          [닫기]      |
+------------------------------------------------------------------+
| 목표 A — 연간 · 2026년 · 복구 12일 남음             [복원]       |
| 이번 달 결과 — 월간 · 2026.11 · 복구 28일 남음      [복원]       |
| 이번 주 결과 — 주간 · 복구 5일 남음                 [복원]       |
+------------------------------------------------------------------+
```

```text
+------------------------------------------------------------------+
| [대시보드] > 목표 A                                               |
+------------------------------------------------------------------+
| 목표 A 제목                            [수정] [상태 변경] [삭제]   |
| 기간: 2026년                         상태: 진행 중                |
| 연간 진행률: 달성 기준 설정하기                                  |
| 확정 기준: 없음                         [기준 관리]             |
|                                                                  |
| 목표 트리                                                         |
| 연간 목표 A                                                       |
|  ├─ 월간 목표 A-1  진행 __%  [상세/계획] [수정] [삭제]              |
|  │   ├─ 주간 목표 A-1-a  진행 __%  [상세/계획] [수정] [삭제]       |
|  │   └─ 주간 목표 A-1-b  진행 __%  [상세/계획] [수정] [삭제]       |
|  └─ 월간 목표 A-2  진행 __%  [상세/계획] [수정] [삭제]              |
+------------------------------------------------------------------+
| 선택한 월간 목표: A-1                       [수정] [삭제]         |

|                                                                  |
| 이번 주 목표                                                     |
| 직전 주 실제 진행: 완료한 일 / 남은 일 (기록 없으면 기록 없음)   |
| 다음 단계 [                                                ]     |
| 주간 목표 [                                              ]       |
| 측정 방식 (•) 체크리스트  ( ) 수치형   현재값 __ / 목표값 __     |
| 귀속 월간 목표 [A-1 선택]  ※ 주간 목표는 한 달에만 연결          |
| [주간 계획 저장]                         [주간 목표 수정] [삭제]  |
+------------------------------------------------------------------+
```

연간 목표 진행률은 사용자가 확정한 달성 기준의 배점 합계로 표시한다. 기준과 배점 합계 100점을 확정하기 전에는 퍼센트 대신 `달성 기준 설정하기`(또는 설정 전 상태)를 표시한다. 확정 시 기본 진행률 0%를 최초 기준선으로 저장하며, 사용자는 선택적으로 이미 달성한 기준을 확인해 그 배점을 반영할 수 있다. 이후 진행률 변화는 최초 기준선 이후 변화만 기록 시작 이후 변화로 표시하고, 가입 전 행동 이력은 추정하지 않는다. 월간·주간 실행 진행률은 별도 표시한다. 체크리스트형 주간 진행률은 연결된 핵심 행동의 완료 비율이다. 수치형은 목표값과 실제 완료값으로 계산하며, 연결 행동에 명시한 기여량은 완료할 때 더하고 완료를 취소하면 되돌린다. 직접 기록은 이번에 추가한 양으로 입력하며 출처를 남긴다. 예를 들어 ‘알고리즘 문제 10개 풀기’에 2문제 행동을 완료하면 실제값에 2를 더한다. 실제값이 14여도 진행 막대는 100%에서 멈추고 완료 색상으로 표시한다. 동일한 행동 완료 요청은 한 번만 반영하지만, 같은 실제 작업을 행동 완료와 직접 기록에 각각 적었는지는 자동으로 완벽히 판별할 수 없어 입력 화면에서 안내한다. 월간 실행률은 기록 없는 하위 주간 목표도 0%로 포함해 가중 평균하고 정수로 반올림한다. 월 경계를 넘는 주간 목표도 하나의 월간 목표에만 연결한다.

```text
|                                                                  |

|   급함   [•]               │ [•]                                  |
|          ───────────────────┼──────────────────                   |
```

오늘 목록은 기본적으로 목표 연결 행동과 `그 밖의 할 일`을 한 목록에 함께 표시하고 출처 배지로 구분한다. 정렬 선택은 `중요도+긴급도`(x+y 합 내림차순, 동점이면 x 내림차순, 다시 동점이면 기존 입력 순서), `중요도`, `긴급도`, `목표 / 그 밖의 할 일 그룹` 네 가지다. 좌표 정렬에서는 사용자가 점을 놓지 않은 항목을 아래에 둔다. 그룹 모드만 두 목록으로 나누며, 두 종류의 완료 수는 항상 따로 요약한다. 각 행에는 완료 체크만 둔다. 아직 사분면에 배치하지 않은 항목의 작은 점은 좌표 영역 바깥·위쪽의 미분류 대기 트레이에 두어 좌표가 없는 상태를 표현한다. 사용자가 점을 사분면에 놓으면 미확정 상태가 되고, 분류를 확정하면 승인된 작은 점이 사분면에 남는다. 키보드 방향키로는 사분면에 배치된 점을 조정한다. 목록 정렬은 화면 표시 순서만 바꾸며 저장된 행동의 기본 순서는 바꾸지 않는다.

할 일 추가는 하나의 폼에서 월간 목표 또는 `그 밖의 할 일`을 먼저 고른 뒤, 목표 연결 행동이면 연결 주간 목표를 고르고, 마지막으로 행동 제목을 입력한다. 연결 주간 목표가 하나면 자동 선택하고 여러 개면 사용자가 선택한다. 연결된 주간 목표가 없으면 저장을 막고 안내를 제공하며, 시연판에 없는 주간 목표 편집 화면으로 연결하지 않는다. `그 밖의 할 일`은 주간 목표 없이 추가한다. 완료 처리는 분류나 확정 전에 언제든 할 수 있고, Maintenance 완료는 목표 진행률에 포함하지 않는다. 하루 첫 진입 때는 미분류 대기 트레이와 사분면을 안내하는 비차단 문구를 보여주고, 분류를 확정한 뒤 같은 날에는 안내를 두드러지게 반복하지 않는다. 중요도·긴급도 영역은 접고 펼칠 수 있으며 오늘의 중요도·긴급도 영역을 열면 좌표 영역 바깥·위쪽의 미분류 대기 트레이와 사분면을 함께 볼 수 있다. 트레이에 남은 항목에는 임시 좌표를 부여하지 않는다. 확정은 사분면에 배치된 미확정 점만 저장하며, 트레이에 남은 점은 미분류 상태를 유지한다.

제품 동작에서는 목표 행동의 `performedDate`(실제 수행일)를 기본적으로 오늘로 두고 사용자가 수정할 수 있으며, 뒤늦게 기록한 행동은 실제 수행일의 기간 리포트에 한 번 집계한다. 별도의 달력 항목은 `해야 할 일`과 `일정`으로 구분한다. 해야 할 일의 마감일은 해당 날짜 칸에, 기간 일정은 시작일~종료일 칸에 표시한다. 대시보드에는 미완료 해야 할 일 전체와 가까운 일정·최근 지난 일정만 정해진 범위대로 보여 준다. 달력 항목 완료와 목표 행동 완료는 별도 기록이며, 달력 항목 완료만으로 행동의 수행일이나 목표 진행률을 만들어 내지 않는다. 정적 프로토타입의 오늘 행동 추가 폼은 수행일 편집을 제공하지 않고 오늘을 기본값으로 사용한다.

목표 연결 행동은 x >= 50인 오른쪽 절반에서만 배치할 수 있고 긴급도 y는 자유롭게 고른다. `그 밖의 할 일`은 네 사분면을 모두 사용할 수 있다. 좌표 분류는 목표 진행률이나 완료 상태를 바꾸지 않는다. 완료 처리는 분류와 독립적이다. 기본 진행률 숫자는 시연용 예시이며 새로운 진행률 계산을 수행하지 않는다.

```text
| 올해 목표 진행률 변화                                             |
| 목표       기간 시작     기간 말      변화(%p)    상태/메모       |
| 목표 A       [값]         [값]         [값]       [비교 설명]     |
| 목표 B       설정 전      설정 전       —         기준 설정 전    |
|                                                                  |
| 기록이 없는 행동·활동일·결과는 추정하지 않습니다.                 |
| 직접 돌아보기                                                    |
| 전보다 할 수 있게 된 일 [직접 작성                             ] |
| 다음 기간에 집중할 일 [직접 작성                               ] |
| AI 회고 초안: 해당 기능은 현재 개발 중입니다.                     |

```

기간은 월간·달력 분기·연간 중 선택하고 선택한 유형에 맞는 기간으로 전환한다. 리포트는 실제 수행일과 기록에 근거하며 `그 밖의 할 일`(Maintenance)을 제외한다. 완료한 핵심 행동 수와 활동일 수, 실제 행동 목록 및 결과물을 보여준다. 결과물이 없으면 `기록된 결과물 없음`으로 표시한다. 기준 미확정 또는 최초 기준선 확정 전 목표는 퍼센트 변화 대신 설정 전 상태를 표시한다. 최초 기준선은 기준·배점 합계 100점을 확정할 때 기본 0%로 저장하고, 사용자가 선택적으로 이미 달성한 기준을 확인한 경우 해당 배점을 반영한다. 비교 기간의 시작 기준이나 종료 관측값이 없거나 기준·배점 변경으로 직접 비교할 수 없으면 비교 불가 사유를 표시한다. 가입 전 행동 이력은 추정하지 않는다. 프로토타입의 예시 수치·목표·활동은 정적 시안용 예시이며 실제 사용자 기록으로 간주하지 않는다. 직접 회고와 다음 기간 집중 항목을 작성할 수 있다. AI 회고는 안내만 제공하며 키 입력·결제·AI 호출은 제공하지 않는다.

## 아침에 오늘 할 일 분류하기

오늘 할 일 → 중요도와 긴급도 직접 선택 → 네 칸에서 점 위치 확인 → 오늘 분류 확정. 두 좌표는 각각 0~100이다. 연간·월간 목표 경로의 행동은 중요도 x >= 50인 높은 중요도 절반에만 둘 수 있고, 긴급도 y는 높거나 낮게 선택할 수 있다. `그 밖의 할 일`(Maintenance)은 네 사분면 어디든 둘 수 있다. 분류는 해당 날의 판단 표시값으로 쓰며 저장된 행동 순서나 목표 진행률·집중 성과를 바꾸지 않는다. 사용자가 좌표 기반 정렬을 고르면 화면 표시 순서에는 좌표가 반영된다. 당일에는 다시 열어 수정할 수 있고 재분류에도 같은 제약을 적용한다.

확장판에서 AI를 요청하면 목표 연결, 기한, 필요 준비 시간을 참고해 항목별 x(중요도)·y(긴급도) 좌표와 짧은 추천 이유를 제안한다. 목표 경로 행동은 AI 추천과 사용자가 최종 승인하는 좌표 모두 x >= 50이어야 하며, y는 제한하지 않는다. `그 밖의 할 일`(Maintenance)은 네 사분면 좌표를 모두 추천할 수 있다. 정보가 부족한 경우 단정하지 않는다. 추천 좌표는 사분면에 점으로 표시하며 사용자는 점을 드래그하거나 좌표값을 수정한 뒤 최종 승인한다. 직접 분류는 계속 제공한다. BYOK 또는 유효한 AI 서비스 결제 자격은 향후 확장 범위이며, 제출판에는 `해당 기능은 현재 개발 중입니다.`를 표시한다.

오늘 할 일 화면은 `오늘 할 일`과 현재 날짜 달력 링크를 표시한다. 목표에 연결된 일과 그 밖의 할 일은 각각 완료 수를 별도 요약으로 표시하고, 그룹 표시를 선택했을 때 각 목록에 빈 상태를 제공한다. 기본 화면은 두 종류 배지를 포함하는 단일 목록이다. 완료는 분류 여부와 독립적이다. 중요도·긴급도 영역은 보조 영역으로 접고 펼칠 수 있으며, 미분류 개수와 선택 항목 상세를 제공한다. 목표 연결 행동은 x=50 경계부터 중요 영역으로 허용하고, 그 밖의 할 일은 네 사분면을 사용할 수 있다. 달력은 일정의 마감일을 보여 주고, 실제 행동 수행일은 리포트에 사용한다.

첫 방문 또는 당일 미확정 상태에서는 중요도·긴급도 영역 안에 비차단 분류 안내를 표시한다. 분류를 확정하면 그날 안내를 숨긴다. 완료 체크는 분류와 독립적으로 언제든 할 수 있다.

분류는 좌표 영역 바깥·위쪽의 미분류 대기 트레이에서 작은 점을 사분면으로 드래그해 수행한다. 목록에는 완료 체크만 제공하고 행에 드래그 핸들을 두지 않는다. 트레이의 점은 좌표가 없는 미분류 상태이고, 사분면에 놓인 점은 점 스타일과 미확정 개수로 아직 승인되지 않은 상태를 나타낸다. 점은 포인터 올림·포커스·선택 때 행동명과 분류 상세를 보여주며, 배치한 뒤에는 드래그와 방향키 조작을 지원한다. `[오늘 분류 확정]`은 사분면에 배치된 미확정 좌표만 저장하며 트레이의 항목은 미분류로 남긴다.

오늘 목록의 기본 정렬은 중요도+긴급도 합계 내림차순이며 동점이면 중요도, 그다음 기존 입력 순서로 표시한다. 중요도, 긴급도, 목표/그 밖의 할 일 그룹 정렬도 제공한다. 그룹 정렬 외에는 목표/그 밖의 일 배지를 포함한 단일 목록이다. 미분류 점은 좌표 영역 바깥·위쪽 트레이에 둔다. 트레이 점을 사분면에 놓으면 초안 좌표가 되고, 승인 전에는 미확정 상태로 표시된다. 키보드 방향키로 사분면에 배치된 점을 조절할 수 있다.
