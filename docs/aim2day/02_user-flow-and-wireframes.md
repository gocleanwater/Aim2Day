# Aim2Day 화면 흐름과 저충실도 와이어프레임

> 과제 제출판 화면 구조 초안. 상자 안의 위치와 정보, 사용자가 할 수 있는 동작을 정리한다. 색상·장식·세부 시각 디자인은 다루지 않는다.

## 화면 흐름

### 첫 방문

```text
가입·로그인
    ↓
올해 목표가 있나요?
    ├─ 없음 → 올해 목표 작성
    └─ 있음 → 기존 올해 목표 작성
                    ↓
             이번 달 목표 작성
                    ↓
             이번 주 목표 작성
                    ↓
             오늘 행동 작성
                    ↓
                대시보드
```

### 다시 방문

```text
로그인 → 올해 목표 한도 확인
           ├─ 올해 목표가 없거나 온보딩을 이어야 함 → 온보딩
           └─ 올해 목표 있음 → 대시보드
           ├─ 오늘 행동 기록·완료
           ├─ 목표를 눌러 월간·주간 계획 보기
           ├─ 그 밖의 할 일 기록
           └─ 기간이 끝나면 리포트 보기
```

비회원은 로그인 화면에서 회원가입으로 이동할 수 있다. 첫 방문 회원은 온보딩을 마치면 대시보드로 이동한다. 상단의 주요 메뉴에는 대시보드, 달력, 연간 목표, 리포트를 두고, 로그인한 회원의 계정 영역에는 로그아웃 바로 옆에 설정을 둔다. 연간 목표 메뉴의 카드에서 목표별 상세를 열고, 달력 메뉴에서는 날짜별 일정을 관리한다.

## 첫 방문 네 질문

온보딩은 연간 목표·이번 달 목표·이번 주 결과·오늘 행동의 네 질문으로 이루어진 하나의 순차 경로다(FN-PLAN-01). 각 질문에서 입력한 항목은 바로 위 단계에 연결한다. 연간 달성 기준과 배점은 온보딩에서 요구하지 않는다. 완료 후 연간 목표 상세의 `[기준 관리]`에서 별도로 설정한다.

- 같은 달력연도의 연간 목표는 진행·완료·보류·중단을 합쳐 최대 3개이며, 소프트 삭제된 목표는 한도에서 제외한다(FN-GOAL-01·04). 첫 질문에서는 기존 목표를 포함해 남은 수만 입력할 수 있다.
- 한도에 도달하면 추가 입력을 막고 현재 개수·최대 개수와 기존 목표를 정리할 수 있다는 안내를 표시한다.
- 월간·주간·일일 항목 개수는 제한하지 않는다. 연간 목표 기간은 1월 1일부터 12월 31일까지다.

```text
+------------------------------------------------------------------+
| Aim2Day                                        첫 방문 계획 1 / 4  |
+------------------------------------------------------------------+
|                                                                  |
|  올해 어떤 일에 집중하고 싶나요?                                     |
|                                                                  |
|  [ 연간 목표 제목                                           ]      |
|  [ + 연간 목표 추가 ]   (최대 3개, 현재 1개)                       |
|  한도에 도달하면 추가할 수 없습니다. 목표를 정리한 뒤 다시 시도하세요. |
|                                                                  |
|  연간 목표: 2026년                                                 |
|  기존 목표 포함 최대 3개. 진행·완료·보류·중단 목표를 모두 셉니다.     |
|                                                                  |
|                         [다음: 이번 달 목표]                       |
+------------------------------------------------------------------+
```

```text
+------------------------------------------------------------------+
| Aim2Day                                        첫 방문 계획 2 / 4  |
+------------------------------------------------------------------+
|  그 목표를 위해 이번 달에 이루고 싶은 건 무엇인가요?                    |
|                                                                  |
|  연결할 연간 목표 [ 목표 선택                              v ]      |
|  이번 달에 이루고 싶은 것 [                                  ]      |
|  설명 / 기대 결과          [                                  ]    |
|                                                                  |
|  기간: 선택된 달력 월                                               |
|               [이전]                    [다음: 이번 주 결과]        |
+------------------------------------------------------------------+
```

```text
+------------------------------------------------------------------+
| Aim2Day                                        첫 방문 계획 3 / 4  |
+------------------------------------------------------------------+
|  이번 주에는 어떤 결과를 만들고 싶나요?                          |
|                                                                  |
|  연결할 월간 목표 [ 목표 선택                              v ]   |
|  이번 주 결과             [                                  ]   |
|  측정 방식                (•) 체크리스트  ( ) 수치형             |
|  수치형일 때 목표값       [              ]                       |
|                                                                  |
|  주간 목표는 한 월간 목표에 연결됩니다.                           |
|               [이전]                    [다음: 오늘 행동]         |
+------------------------------------------------------------------+
```

```text
+------------------------------------------------------------------+
| Aim2Day                                        첫 방문 계획 4 / 4  |
+------------------------------------------------------------------+
|  그러면 오늘 해내고 싶은 행동은 무엇인가요?                      |
|                                                                  |
|  먼저 선택       (•) 이번 달 목표  ( ) 그 밖의 할 일             |
|  이번 달 목표    [ 목표 선택                              v ]   |
|  연결할 주간 목표 [ 해당 월간 목표에 주간 목표가 여러 개면 선택 v ]|
|  행동                     [                                  ]   |
|  수행일                   [ 오늘: YYYY.MM.DD              v ]   |
|  [ + 행동 추가 ]                                                 |
|                                                                  |
|  연결된 주간 목표가 하나면 자동 연결하고, 여러 개면 선택합니다.   |
|  그 밖의 할 일은 목표 경로 없이 저장됩니다.                      |
|               [이전]                    [계획 완료]              |
+------------------------------------------------------------------+
```

첫 번째 질문은 1월에 `올해 어떤 일에 집중하고 싶나요?`, 2~12월에 `올해 남은 기간에 어떤 일에 집중하고 싶나요?`로 표시한다. 두 번째 질문은 모든 달에 `그 목표를 위해 이번 달에 이루고 싶은 건 무엇인가요?`로 표시하며, 세 번째와 네 번째 질문은 명세 문구 그대로 사용한다. 날짜와 주 시작 요일에 따라 이번 달·이번 주 기간을 표시한다.

## 로그인

```text
+------------------------------------------------------------------+
| Aim2Day                                                           |
+------------------------------------------------------------------+
|                         로그인                                    |
|                                                                  |
|  이메일 [                                                  ]   |
|  비밀번호             [                                      ]   |
|                                                                  |
|  [로그인]                                                        |
|  회원가입                                      비밀번호 재설정    |
+------------------------------------------------------------------+
```

로그인 성공 후 올해 목표가 없으면 네 질문 온보딩으로, 올해 목표가 있으면 대시보드로 이동한다. 올해 목표 존재 여부와 개수는 진행·완료·보류·중단 상태를 합산하고 소프트 삭제 목표는 제외해 판단한다. 이메일 인증을 마치지 않은 계정은 로그인할 수 없으며, 로그인 화면에 `이메일 인증 후 로그인할 수 있습니다.`와 `[인증 메일 다시 보내기]`를 표시한다. 회원가입과 비밀번호 재설정은 제출판 인증 절차를 제공한다.

## 회원가입

```text
+------------------------------------------------------------------+
| Aim2Day                                                           |
+------------------------------------------------------------------+
|                         회원가입                                  |
|                                                                  |
|  이메일          [                                          ]    |
|                  로그인과 인증 메일 수신에 사용합니다.            |
|  사용자명        [                                          ]    |
|                  화면에 표시되는 이름입니다. 다른 사람과 같아도 됩니다. |
|  비밀번호        [                                          ]    |
|  비밀번호 확인   [                                          ]    |
|                                                                  |
|  [가입하기]                                                      |
|  이미 계정이 있나요? 로그인                                      |
+------------------------------------------------------------------+
```

```text
+------------------------------------------------------------------+
| Aim2Day                                                           |
+------------------------------------------------------------------+
|                    인증 메일을 보냈습니다                         |
|                                                                  |
|  user@example.com 으로 보낸 링크를 열어 인증을 마쳐 주세요.       |
|  링크는 일정 시간이 지나면 만료되며 한 번만 사용할 수 있습니다.   |
|  인증을 마쳐야 로그인할 수 있습니다.                             |
|                                                                  |
|  [인증 메일 다시 보내기]                      [로그인으로 이동]   |
+------------------------------------------------------------------+
```

가입 시 이메일 형식, 이미 가입된 이메일, 비어 있는 사용자명, 비밀번호와 비밀번호 확인의 불일치를 입력란 아래에 안내한다. 이메일은 계정마다 하나만 쓸 수 있고 사용자명은 중복을 허용한다. 가입 요청이 성공하면 인증 메일 안내 화면으로 이동한다. 메일 전송에 실패하면 가입이 끝난 것처럼 보이지 않게 실패를 알리고 `[인증 메일 다시 보내기]`를 제공한다. 메일의 인증 링크를 열면 결과 화면에서 인증 완료 또는 만료·이미 사용한 링크임을 알리고 로그인으로 이동할 수 있게 한다. 비밀번호는 8~64자이며 영문·숫자·특수문자를 각각 1자 이상 포함해야 한다(FN-AUTH-01).

## 대시보드

```text
+------------------------------------------------------------------+
| Aim2Day [대시보드] [달력] [연간 목표] [리포트]   [로그아웃] [설정] |
+------------------------------------------------------------------+
| 오늘 행동   [◀] [2026.11.12 ▦] [▶] [오늘]       [+ 행동 추가]     |
| [ ] 목표 연결 행동 — 목표 경로                                  |
| [ ] 그 밖의 할 일                                                |
| ▸ 지난 미완료 N개 · ▸ 오늘의 중요도·긴급도   (오늘에만 표시)      |
+------------------------------------------------------------------+
| 해야 할 일                          | 일정                       |
| [ ] 과제 제출 — D-2               | [ ] 발표 — 내일             |
| [ ] 장학금 신청 — 기한 지남        | [ ] 여행 — 진행 중          |
| 완료 전 모든 항목                   | 오늘~7일 이내 + 진행 중     |
|                                    | ▸ 지난 일정 · 최근 7일      |
+------------------------------------------------------------------+
| 이번 주 계획                                                      |
| 주간 목표 — 연간 목표 > 월간 목표 — 진행률 — [상세]               |
| [이번 주 목표 설정]                                               |
| 주간 목표와 연결된 일정 요약                                      |
+------------------------------------------------------------------+
| 이번 달 계획                                                      |
| 월간 목표 — 연간 목표 — 진행률 — [상세]                           |
| 다음 단계와 주요 일정 요약                                        |
| [이번 달 목표 설정]                                               |
+------------------------------------------------------------------+
| 최근 진행 기록: 날짜 · 변경 항목 · 메모                           |
+------------------------------------------------------------------+
```

대시보드 본문은 `오늘 행동 → 해야 할 일 | 일정 → 이번 주 → 이번 달` 순서다(FN-DASH-01). 좁은 화면에서는 두 열을 세로로 쌓는다.

- `해야 할 일`은 완료 전까지 기한과 관계없이 모두 보여 주고, 완료하면 목록에서 내린다.
- `일정`은 오늘부터 7일 이내의 항목과 진행 중인 기간 항목을 보여 준다.
- 최근 7일 안에 끝난 일정은 접힌 `지난 일정`에 종료일 기준 `D+1`처럼 표시한다. 더 오래된 일정은 달력에서 조회한다.
- 두 종류 모두 완료 체크를 제공한다. 날짜와 남은 일수는 계정 시간대를 따른다. 기한 당일은 `오늘`, 기한이 지난 `해야 할 일`은 `기한 지남`으로 표시한다.
- 목표 연결 항목은 목표 이름과 색상으로 표시한다.
- `[이번 달 목표 설정]`과 `[이번 주 목표 설정]`은 월간·주간 목표 설정 화면으로 이동한다.
- 연간 목표 카드와 시간 경과 지표는 표시하지 않는다.

날짜 이동은 오늘 행동 영역에만 적용한다. `해야 할 일 | 일정`, 이번 주, 이번 달 영역은 날짜를 바꿔도 오늘 기준을 유지한다.

### 오늘 행동 영역

오늘 행동 영역은 그날의 행동을 완료하고, 오늘 분류를 확정하는 곳이다. 목표 연결 행동과 `그 밖의 할 일`을 한 목록에 함께 보여 준다. 오늘 기준 화면은 다음과 같다.

```text
+------------------------------------------------------------------+
| 오늘 행동   [◀] [2026.11.12 ▦] [▶] [오늘]            0 / 3 완료   |
|                                                                  |
| 목표 연결 0/2 완료 · 그 밖의 할 일 0/1 완료    정렬 [중요도+긴급도 v]|
|       (정렬: 중요도+긴급도 / 중요도 / 긴급도 / 목표 그룹)         |
|                                                                  |
| [ ] 알고리즘 문제 2개 풀기                             [목표]     |
|      백엔드 개발자 취업 준비 › 2026.11 월 목표 › 이번 주 목표     |
|      확정 · 중요도 72 · 긴급도 70                                 |
| [ ] 풀이 과정에서 막힌 부분 정리하기                   [목표]     |
|      백엔드 개발자 취업 준비 › 2026.11 월 목표 › 이번 주 목표     |
|      재분류 중 · 중요도 80 · 긴급도 70 (확정 위치 중요도 65 · 긴급도 50) |
| [ ] 그 밖의 할 일 예시                                [그 밖의 일]|
|      되돌리기 대기 · 확정 위치 중요도 30 · 긴급도 40              |
| [ ] 새로 추가한 행동                                   [목표]     |
|      미분류                                                      |
|                                                                  |
| 월간 목표/종류 [목표 선택 v] [주간 목표 v] [행동 제목] [+ 추가]   |
|  ※ 그 밖의 할 일은 주간 목표가 필요 없음                         |
|                                                                  |
| ▸ 지난 미완료 2개                                                |
|   [ ] 운동하기 · 2026.11.11            [오늘로 옮기기]            |
|   [ ] 오답 노트 정리하기 · 2026.11.10   [오늘로 옮기기]            |
|                                                                  |
| ▾ 오늘의 중요도·긴급도                                           |
|   첫 방문 안내: 점을 끌어 중요도와 긴급도를 정해 보세요.          |
|   미분류 1개 · 확정 대기 2개                                      |
|   미분류 대기 트레이: [•]       (좌표 영역 바깥·위쪽)              |
|   중요도 낮음              │ 중요함                              |
|   급함   [•]               │ [•] ← 재분류 중 점                   |
|          ───────────────────┼──────────────────                   |
|   여유 있음 [•]             │ (○) ← 확정 위치(흐린 표시)          |
|   점을 사분면으로 드래그 · 트레이로 끌어 되돌리기 · 방향키 조정     |
|   선택 점 상세: 제목 · 목표 경로 · 사분면 · 점 상태               |
|   [오늘 분류 확정] [변경 취소] [선택한 점 트레이로 보내기: 대체 수단] |
|   [AI 추천 · 준비 중]                                             |
+------------------------------------------------------------------+
```

다른 날짜를 고르면 다음과 같이 바뀐다.

```text
+------------------------------------------------------------------+
| 2026.11.11 행동   [◀] [2026.11.11 ▦] [▶] [오늘]       1 / 2 완료  |
| 지난 날짜에는 행동을 추가하고, 체크를 잊은 행동을 완료할 수 있어요. |
| [x] 영어 기술 문서 한 단락 요약하기                    [목표]     |
|      확정 · 중요도 70 · 긴급도 60                                 |
| [ ] 운동하기                                      [그 밖의 일]    |
|      미분류                                                      |
| 월간 목표/종류 [목표 선택 v] [주간 목표 v] [행동 제목] [+ 추가]   |
|  (사분면 분류, 미분류 트레이, 지난 미완료 영역 없음)               |
+------------------------------------------------------------------+
| 2026.11.13 행동   [◀] [2026.11.13 ▦] [▶] [오늘]        0 / 1 완료  |
| 미래 날짜에는 행동을 미리 추가할 수 있어요. 완료 체크는 그날부터 할 수 있어요. |
| [ ] (비활성) 발표 자료 초안 만들기                     [목표]     |
+------------------------------------------------------------------+
| 2026.11.20 행동   [◀] [2026.11.20 ▦] [▶] [오늘]        0 / 0 완료  |

| 월간 목표/종류 [그 밖의 할 일 v] [행동 제목] [+ 추가]              |
```

위 마지막 화면은 현재 주(이 예시에서는 11.08~11.14) 이후 날짜를 본 경우다.

#### 날짜 이동

FN-DASH-03을 따른다.

- `[◀]`·`[▶]`는 하루씩 이동한다. 날짜 칸에 직접 입력하거나 `▦`로 달력을 열어 고르면 그 날짜로 이동한다. `[오늘]`은 오늘로 돌아온다.
- 잘못된 날짜를 입력하면 이동하지 않고 입력란 아래에 안내한다.
- 오늘이 아니면 영역 제목을 `2026.11.11 행동`처럼 날짜로 바꾼다. 완료 수 요약도 그 날짜의 행동 기준이다.
- 지난 날짜에는 그 날짜를 수행일로 행동을 추가하고, 체크를 잊은 행동을 완료할 수 있다.
- 미래 날짜에는 행동을 추가할 수 있지만 완료 체크는 비활성화하고 안내 문구를 보여 준다.
- 현재 주 이후 날짜에서는 추가 폼에 `그 밖의 할 일`만 선택할 수 있고, 월간 목표 선택은 비활성화한다. 폼 아래에 `다음 주 이후 날짜에는 목표 행동을 추가할 수 없어요. 그 주가 되면 주간 목표를 만든 뒤 추가하세요.`를 보여 준다(FN-ACT-01).
- 사분면 분류와 `지난 미완료`는 오늘에만 표시한다. 다른 날짜에서는 그날 확정한 좌표를 목록의 상태 문구로 볼 수만 있다. 확정하지 않은 변경은 보이지 않고, 확정한 좌표가 없으면 `미분류`로 표시한다(FN-QUAD-02).

#### 목록과 정렬

FN-ACT-03을 따른다.

- 기본 화면은 단일 목록이며, 출처 배지(`목표`, `그 밖의 일`)로 구분한다.
- 정렬은 `중요도+긴급도`(기본), `중요도`, `긴급도`, `목표 / 그 밖의 할 일 그룹` 네 가지다. 좌표 정렬에서는 점을 놓지 않은 항목을 아래에 둔다. 정렬은 화면 표시 순서만 바꾼다.
- 그룹 모드만 두 목록으로 나누고, 각 목록에 빈 상태 문구를 보여 준다. 두 종류의 완료 수는 항상 따로 요약한다.
- 각 행에는 완료 체크와 점 상태 문구만 둔다. 행에 드래그 핸들은 두지 않는다. 완료는 분류와 무관하게 언제든 할 수 있다.
- 행동을 삭제하면 목록에서 숨긴다. 완료한 행동은 삭제해도 리포트와 수치 기록에 남는다(FN-ACT-02).

#### 행동 추가

FN-ACT-01을 따른다. 하나의 폼에서 월간 목표 또는 `그 밖의 할 일`을 먼저 고르고, 목표 연결 행동이면 주간 목표를 고른 뒤 행동 제목을 입력한다.

- 연결된 주간 목표가 하나면 자동 선택하고, 여러 개면 선택하게 한다.
- 연결된 주간 목표가 없으면 저장을 막고 안내한다. 시연판에는 주간 목표 편집 화면 연결이 없다.
- 수치형 주간 목표에는 완료 시 더할 기여 수치를 입력할 수 있다.
- 수행일은 지금 보고 있는 날짜가 기본값이다. 정적 프로토타입은 수행일 편집을 제공하지 않는다. 제품에서는 수행일을 수정할 수 있고, 뒤늦게 기록한 행동은 실제 수행일의 기간 리포트에 한 번 집계된다.
- 달력 항목(`해야 할 일`·`일정`)의 완료는 행동 완료와 별개이며, 수행일이나 진행률을 만들지 않는다.

#### 지난 미완료

FN-ACT-04를 따른다. 수행일이 오늘 이전이고 완료하지 않은 행동을 오늘 목록 아래의 접힌 `지난 미완료 N개` 영역에 보여 준다.

- 각 행은 제목과 원래 수행일, 완료 체크, `[오늘로 옮기기]`로 이루어진다.
- `[오늘로 옮기기]`는 수행일을 오늘로 바꿔 오늘 목록에 넣는다.
- 완료 체크는 원래 수행일을 유지한 채 완료 처리하며, 그날의 리포트에 집계된다.
- 날이 바뀌어도 수행일을 자동으로 바꾸지 않는다.
- 이 영역의 행동은 오늘 완료 수 요약과 사분면에 포함하지 않는다.

#### 사분면 분류

FN-QUAD-01·02를 따른다. 중요도 x와 긴급도 y는 각각 0~100이다.

- 미분류 점은 좌표 영역 바깥·위쪽의 미분류 대기 트레이에 둔다. 트레이의 점에는 임시 좌표를 주지 않는다.
- 트레이의 점을 사분면으로 드래그하면 미확정 상태가 된다. 배치한 뒤에는 드래그와 방향키로 조정한다.
- 배치한 점을 트레이로 되돌리는 기본 방법은 점을 트레이로 끌어 놓는 것이다. 트레이가 비어 있어도 목적지로 보이도록 영역을 유지한다.
- 목표 연결 행동은 x >= 50인 오른쪽 절반에만 놓을 수 있고 y는 자유롭다. `그 밖의 할 일`은 네 사분면 모두 쓸 수 있다.
- 점은 포인터를 올리거나 포커스·선택할 때 행동명과 분류 상세를 보여 준다.
- 중요도·긴급도 영역은 접고 펼칠 수 있다. 하루 첫 진입이나 확정 전에는 비차단 안내 문구를 보여 주고, 확정한 뒤 같은 날에는 숨긴다.
- 분류는 해당 날의 판단 표시값이다. 저장된 행동 순서, 완료 상태, 진행률을 바꾸지 않는다.

확정한 위치는 `[오늘 분류 확정]`을 다시 누르기 전까지 유지한다. 확정한 점을 옮기거나 트레이로 보내도 이전 확정 위치를 덮어쓰지 않고 미확정 변경으로만 둔다. 점 상태는 다섯 가지다.

| 상태 | 의미 | 점 표시 |
|---|---|---|
| 미분류 | 확정 위치가 없고 트레이에 있다 | 트레이 |
| 미확정 | 처음 배치했고 아직 확정하지 않았다 | 사분면, 미확정 점 스타일 |
| 확정 | 마지막 확정 위치에 있다 | 사분면 |
| 재분류 중 | 확정한 점을 새 위치로 옮겼다 | 새 위치 + 확정 위치의 흐린 표시 |
| 되돌리기 대기 | 확정한 점을 트레이로 보냈다 | 트레이, 미확정 점 스타일 + 확정 위치의 흐린 표시 |

버튼은 다음과 같이 동작한다.

- `[오늘 분류 확정]`: 사분면에 놓인 점의 현재 위치를 확정한다. 트레이에 있는 점은 미분류가 된다. `되돌리기 대기` 점은 확정 위치가 없어진다.
- `[변경 취소]`: 확정하지 않은 변경을 모두 버리고 마지막 확정 상태로 되돌린다. 확정한 적 없는 점은 미분류로 돌아간다. 변경이 없으면 비활성화한다.
- `[선택한 점 트레이로 보내기]`: 트레이로 끌어 놓기의 대체 수단이다. 좌표판에서 선택한 점을 트레이로 보낸다. 점에 포커스를 두고 Delete 키를 눌러도 같다. 드래그가 어려운 키보드·보조 기술 사용자도 점 선택, 방향키 조정, 트레이 되돌리기를 모두 할 수 있게 하려는 것이다. 확정한 점이면 `되돌리기 대기`가 된다.
- `[AI 추천 · 준비 중]`: `해당 기능은 현재 개발 중입니다.`를 표시한다. 확장판에서는 AI가 추천 좌표를 점으로 제안하고 사용자가 수정·승인한 뒤 확정하지만, 목표 연결 행동은 추천과 승인 좌표 모두 x >= 50이어야 한다. 직접 분류는 계속 제공한다.

영역 위쪽에는 `미분류 N개 · 확정 대기 N개`를 표시한다. `확정 대기`는 미확정·재분류 중·되돌리기 대기 점의 합이다.

### 월간·주간 목표 설정

```text
+------------------------------------------------------------------+
| [대시보드] > 월간·주간 목표 설정                                  |
+------------------------------------------------------------------+
| 큰 목표에서 이번 달의 결과를 정하고, 그 결과를 이번 주 목표로 구체화 |
+------------------------------------------------------------------+
| 이번 달 목표 만들기                                               |
| 연결할 올해 목표 [목표 선택 v]                                    |
| 이번 달에 이루고 싶은 결과 [                                  ]   |
| [월간 목표 저장]                                                  |
+------------------------------------------------------------------+
| 이번 주 목표 만들기                                               |
| 연결할 이번 달 목표 [목표 선택 v]                                 |
| 이번 주에 이루고 싶은 결과 [                                  ]  |
| 측정 방식 [수치형 v / 행동 체크형]                                |
| 목표 수치 [          ] (수치형 선택 시)                           |
| [주간 목표 저장]                                                  |
+------------------------------------------------------------------+
| 설정한 목표                                                       |
| 연간 목표 › 월간 목표                         [수정] [삭제]       |
|   연간 목표 › 월간 목표 › 주간 목표           [수정] [삭제]       |
+------------------------------------------------------------------+
```

대시보드의 두 설정 버튼은 같은 설정 화면으로 이동한다. 월간 목표는 연간 목표를 부모로 선택하고 현재 달의 결과를 입력한다. 대상 월은 현재 달로 자동 결정되며 선택하거나 입력하는 항목이 없다. 주간 목표는 월간 목표를 부모로 선택하고 이번 주 결과와 측정 방식을 정한다. 수치형이면 목표 수치를 입력하며, 행동 체크형이면 핵심 행동 완료 여부로 진행을 기록한다. 월간 목표를 먼저 저장해야 그 목표를 주간 부모로 선택할 수 있다. 정적 시안에 표시된 목표명·수치는 화면 흐름 예시이며 사용자의 실제 목표나 기록을 뜻하지 않는다.


`오늘`은 현재 날짜로 즉시 이동한다. 주 표시와 날짜 경계는 사용자 설정을 따르며 초기 설정은 일요일 시작이다. 월간 달력은 날짜마다 독립된 칸을 사용한다. **해야 할 일**은 마감일 칸에, 하루 일정은 해당 날짜 칸에, 기간 일정은 시작일부터 종료일까지 목표 색상의 작은 칩으로 표시한다. 날짜 칸 안의 칩이나 빈 공간을 누르면 해당 날짜를 선택하고 아래 선택 날짜 목록으로 이동한다. 완료한 항목은 칩과 목록에서 옅게 표시하고 왼쪽 색상 막대를 제거한다. 사용자는 종류를 선택해 달력 항목을 생성·수정·완료 처리할 수 있다. 목표 필터에서 목표별 항목을 선택하거나 숨길 수 있고, 목표 미연결 `Maintenance` 항목도 별도 선택할 수 있다. 목표 이름과 색상은 해당 목표 설정을 따른다. 목표 행동의 실제 수행일은 달력 항목과 분리해 리포트에 사용한다.

```text
+------------------------------------------------------------------+
```

목표 카드는 가용 폭이 충분하면 가로로 나열하고, 좁은 화면에서는 세로로 쌓는다. `[상세]`를 누르면 해당 목표 상세를 연다. 순서 편집은 목록 전체를 재배치하고 저장하며, 다음 방문에도 같은 순서를 유지한다. 연간 목표 카드와 상세에서, 월간·주간 목표는 설정 목록에서 수정·삭제를 제공하고, 소프트 삭제된 목표는 `[삭제된 목표 보기]`에서 복원할 수 있다. 연간 목표는 최대 3개이며, 한도에 도달하면 추가와 한도 초과 복원을 막고 현재 개수·최대 개수와 가능한 조치를 안내한다. 각 목표 이름과 색상은 목표별 설정에서 변경한다. 상위 목표 삭제 시 확인 창을 거쳐 하위 목표와 그 경로의 미완료 핵심 행동을 숨기며, 상위 목표를 복원하면 원래 연결을 유지한 채 다시 표시한다. 완료된 행동 기록은 삭제하지 않는다.

### 연간 목표 상세

```text
+------------------------------------------------------------------+
| [연간 목표] > 목표 A         [수정] [상태 변경] [삭제]            |
+------------------------------------------------------------------+
| 목표 이름 [목표 A]   표시 색상 [색상 선택]   기간 2026년          |
| 설명 [                                                       ]   |
| 달성 기준 설정 전: 달성 기준 설정하기                           |
|                                                                  |
| 하위 목표                                                         |
| 월간 목표 A-1 — 진행률 __% — [상세]                               |
|   주간 목표 A-1-a — 진행률 __% — [상세]                           |
| [삭제된 목표 보기]                                                 |
+------------------------------------------------------------------+
```

### 삭제된 목표 보기

삭제된 목표 목록에는 목표 단계와 관계없이 삭제 시각부터 30일 이내에 복원할 수 있는 항목과 남은 기간을 표시한다. 복원할 때는 연간 목표 개수 한도를 다시 검사한다. 삭제 확인 화면에는 다음을 안내한다.

- 30일 뒤 앞으로의 계획과 미완료 행동은 영구 삭제된다.
- 완료한 목표·행동과 달성한 기준은 과거 이력으로 남는다.

복구 기간이 끝난 계획은 복원할 수 없고, 과거 이력은 새 목표나 행동의 부모로 선택할 수 없다.

```text
+------------------------------------------------------------------+
| 삭제된 목표                                          [닫기]      |
+------------------------------------------------------------------+
| 목표 A — 연간 · 2026년 · 복구 12일 남음             [복원]       |
| 이번 달 결과 — 월간 · 2026.11 · 복구 28일 남음      [복원]       |
| 이번 주 결과 — 주간 · 복구 5일 남음                 [복원]       |
+------------------------------------------------------------------+
```

## 목표 상세와 월·주 계획

연간 목표 상세에서 `[상세/계획]`을 누르면 하위 목표 트리와 선택한 월간 목표의 이번 주 계획을 함께 본다.

```text
+------------------------------------------------------------------+
| [대시보드] > 목표 A                                               |
+------------------------------------------------------------------+
| 목표 A 제목                            [수정] [상태 변경] [삭제]   |
| 기간: 2026년                         상태: 진행 중                |
| 연간 진행률: 달성 기준 설정하기                                  |
| 확정 기준: 없음                         [기준 관리]             |
|                                                                  |
| 목표 트리                                                         |
| 연간 목표 A                                                       |
|  ├─ 월간 목표 A-1  진행 __%  [상세/계획] [수정] [삭제]              |
|  │   ├─ 주간 목표 A-1-a  진행 __%  [상세/계획] [수정] [삭제]       |
|  │   └─ 주간 목표 A-1-b  진행 __%  [상세/계획] [수정] [삭제]       |
|  └─ 월간 목표 A-2  진행 __%  [상세/계획] [수정] [삭제]              |
+------------------------------------------------------------------+
| 선택한 월간 목표: A-1                       [수정] [삭제]         |
| 기간 2026.11 (현재 달)  결과/설명 [                         ]   |
|                                                                  |
| 이번 주 목표                                                     |
| 직전 주 실제 진행: 완료한 일 / 남은 일 (기록 없으면 기록 없음)   |
| 다음 단계 [                                                ]     |
| 주간 목표 [                                              ]       |
| 측정 방식 (•) 체크리스트  ( ) 수치형   현재값 __ / 목표값 __     |
| 귀속 월간 목표 [A-1 선택]  ※ 주간 목표는 한 달에만 연결          |
| [주간 계획 저장]                         [주간 목표 수정] [삭제]  |
+------------------------------------------------------------------+
```

연간 진행률은 사용자가 확정한 달성 기준의 배점 합계로 표시한다(FN-CRIT-01).

- 기준과 배점 합계 100점을 확정하기 전에는 퍼센트 대신 `달성 기준 설정하기`를 표시한다.
- 확정하면 최초 기준선(기본 0%)을 저장한다. 이미 달성한 기준을 선택해 그 배점을 반영할 수 있다.
- 연간 진행률의 변화는 최초 기준선 이후만 보여 준다. 가입 전 행동 이력은 추정하지 않는다.

월간·주간 실행 진행률은 연간 진행률과 따로 표시하며 계산은 FN-PROG-01·02를 따른다. 수치형 주간 목표의 실제값이 목표값을 넘어도 막대는 100%에서 멈추고 완료 색으로 표시한다. 행동 완료와 직접 기록에 같은 작업을 이중으로 적지 않도록 입력 화면에서 안내한다. 월 경계를 넘는 주간 목표도 하나의 월간 목표에만 연결한다.

## 기본 리포트

```text
+------------------------------------------------------------------+
| [대시보드] > 리포트                                               |
+------------------------------------------------------------------+
| 기준 월 [◀] [2026.12 ▦] [▶]                                      |
| ┌─────────────┬─────────────┬─────────────┐                      |
| │ 2026.12 월간 │ 2026 4분기  │ 2026년 연간 │                      |
| └─────────────┴─────────────┴─────────────┘                      |
|  (기준 월에 끝나는 기간만 탭으로 표시. 11월이면 월간 탭 하나)    |
|                                                                  |
| 완료한 핵심 행동 [개수]              기록된 활동일 [개수]         |
| 무엇을 했나요?                                                    |
| • 실제 수행일 · 완료 행동 목록                                    |

| 올해 목표 진행률 변화                                             |
|        목표 A               목표 B             목표 C             |
| 100% ┤                                                           |
|      │         ██                          기준 설정 전          |
|      │   ░░    ██               ██                               |

|                         (12.05)                                  |
|        20%    35%         0%       20%                           |
|          +15%p               +20%p                               |
|                                                                  |
| 기간 중 기준·배점을 바꾼 목표: 막대 없이 비교 불가 (기준·배점 변경) |
```

FN-REPORT-04를 따른다.

#### 기준 월과 탭

- 기준 월은 이번 달이 기본값이다. `[◀]`·`[▶]`나 `▦`로 바꾼다.
- 기준 월에 끝나는 기간만 화면 위쪽 탭으로 보여 준다. 탭은 웹 브라우저 탭처럼 `월간 → 분기 → 연간` 순서로 나란히 둔다.
- 월간 탭은 모든 달에 있다. 3·6·9·12월에는 분기 탭이, 12월에는 연간 탭이 더해진다. 예: 3월은 `2026.03 월간`·`2026 1분기`, 12월은 `2026.12 월간`·`2026 4분기`·`2026년 연간`.
- 기준 월을 바꾸면 첫 탭인 월간 탭이 열린다.
- 각 탭은 자기 기간의 집계와 직접 회고를 따로 보여 준다. 진행 중인 기간도 오늘까지의 기록으로 볼 수 있다.

#### 목표 진행률 막대

목표마다 세로 막대 두 개를 보여 준다. 높이는 0~100%이며 목표 색상을 쓴다.

- 왼쪽 막대는 지난 기간 말(이번 기간 시작 직전), 오른쪽 막대는 이번 기간 말의 달성률이다. 막대 아래에 기간 라벨(`10월 말`, `11월 말`), 달성률, 변화(`+15%p`)를 숫자로 함께 적는다. 막대에는 같은 값을 읽어 주는 접근성 문구를 둔다.
- 이번 기간 중에 달성 기준을 처음 확정한 목표는 왼쪽 막대를 `기록 시작 (11.05)`(최초 기준선)으로 표시한다.
- 달성 기준 설정 전인 목표는 막대 대신 `기준 설정 전`을 표시한다.
- 기간 중 기준·배점을 바꿨거나 시작·종료 값이 없어 비교할 수 없는 목표는 막대 대신 `비교 불가 (기준·배점 변경)`처럼 사유를 표시한다.
- 가입 전 행동 이력은 추정하지 않는다. 최초 기준선과 달성률 계산은 FN-REPORT-02와 FN-CRIT-01을 따른다.

#### 집계와 회고

- 리포트는 실제 수행일과 기록에 근거하며 `그 밖의 할 일`을 제외한다(FN-REPORT-01). 완료한 핵심 행동 수, 활동일 수, 완료 행동 목록, 결과물을 보여 준다. 결과물이 없으면 `기록된 결과물 없음`으로 표시한다.
- 완료한 행동을 삭제해 목록에서 숨겨도 리포트에는 남는다.
- `전보다 할 수 있게 된 일`과 `다음 기간에 집중할 일`을 직접 작성한다(FN-REPORT-03). AI 회고는 안내 문구만 제공하며 키 입력·결제·AI 호출은 없다.
- 프로토타입의 예시 수치·목표·활동은 정적 시안용이며 실제 사용자 기록이 아니다.
