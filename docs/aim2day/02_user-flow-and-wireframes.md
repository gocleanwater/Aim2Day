# Aim2Day 화면 흐름과 저충실도 와이어프레임

> 과제 제출판 화면 구조 초안. 상자 안의 위치와 정보, 사용자가 할 수 있는 동작을 정리한다. 색상·장식·세부 시각 디자인은 다루지 않는다.

## 화면 흐름

### 첫 방문

```text
가입·로그인
    ↓
올해 목표가 있나요?
    ├─ 없음 → 올해 목표 작성
    └─ 있음 → 기존 올해 목표 작성
                    ↓
             이번 달 목표 작성
                    ↓
             이번 주 목표 작성
                    ↓
             오늘 행동 작성
                    ↓
                대시보드
```

### 다시 방문

```text
로그인 → 대시보드
           ├─ 오늘 행동 기록·완료
           ├─ 목표를 눌러 월간·주간 계획 보기
           ├─ 챙길 일 기록
           └─ 기간이 끝나면 리포트 보기
```

비회원은 로그인 화면에서 계정이 없는 경우 회원가입으로 이동할 수 있다. 첫 방문 회원은 온보딩을 마치면 대시보드로 이동한다. 대시보드에서 목표 상세, 오늘 행동, 기본 리포트, 설정으로 이동할 수 있다. 목표 상세에서 월간·주간 계획을 확인하거나 작성한다.

## 첫 방문 네 질문

온보딩은 하나의 순차 경로다. 각 질문에서 입력한 항목은 바로 위 단계에 연결한다. 연간 목표는 여러 개를 추가할 수 있으며, 기존에 가진 올해 목표와 사용자가 확인한 기존 달성 기준도 입력할 수 있다. 연간 목표 기간은 1월 1일부터 12월 31일까지다.

```text
+------------------------------------------------------------------+
| Aim2Day                                        첫 방문 계획 1 / 4  |
+------------------------------------------------------------------+
|                                                                  |
|  올해 어떤 일에 집중하고 싶나요?                                     |
|                                                                  |
|  [ 연간 목표 제목                                           ]      |
|  [ 설명 또는 올해의 달성 기준 초안                        ]          |
|  [ + 연간 목표 추가 ]                                              |
|                                                                  |
|  연간 목표: 2026년                                                 |
|  기존에 가진 올해 목표도 적을 수 있습니다.                            |
|                                                                  |
|                         [다음: 이번 달 목표]                       |
+------------------------------------------------------------------+
```

```text
+------------------------------------------------------------------+
| Aim2Day                                        첫 방문 계획 2 / 4  |
+------------------------------------------------------------------+
|  그 목표를 위해 이번 달에 이루고 싶은 건 무엇인가요?                    |
|                                                                  |
|  연결할 연간 목표 [ 목표 선택                              v ]      |
|  이번 달에 이루고 싶은 것 [                                  ]      |
|  설명 / 기대 결과          [                                  ]    |
|                                                                  |
|  기간: 선택된 달력 월                                               |
|               [이전]                    [다음: 이번 주 결과]        |
+------------------------------------------------------------------+
```

```text
+------------------------------------------------------------------+
| Aim2Day                                        첫 방문 계획 3 / 4  |
+------------------------------------------------------------------+
|  이번 주에는 어떤 결과를 만들고 싶나요?                          |
|                                                                  |
|  연결할 월간 목표 [ 목표 선택                              v ]   |
|  이번 주 결과             [                                  ]   |
|  측정 방식                (•) 체크리스트  ( ) 수치형             |
|  수치형일 때 목표값       [              ]                       |
|                                                                  |
|  주간 목표는 한 월간 목표에 연결됩니다.                           |
|               [이전]                    [다음: 오늘 행동]         |
+------------------------------------------------------------------+
```

```text
+------------------------------------------------------------------+
| Aim2Day                                        첫 방문 계획 4 / 4  |
+------------------------------------------------------------------+
|  그러면 오늘 해내고 싶은 행동은 무엇인가요?                      |
|                                                                  |
|  연결할 주간 목표 [ 목표 선택                              v ]   |
|  행동                     [                                  ]   |
|  수행일                   [ 오늘: YYYY.MM.DD              v ]   |
|  [ + 행동 추가 ]                                                 |
|                                                                  |
|  행동은 연결된 주간 목표와 함께 저장됩니다.                       |
|  챙길 일은 목표와 직접 연결되지 않는 생활상 할 일입니다.         |
|               [이전]                    [계획 완료]              |
+------------------------------------------------------------------+
```

첫 번째 질문은 1월에 `올해 어떤 일에 집중하고 싶나요?`, 2~12월에 `올해 남은 기간에 어떤 일에 집중하고 싶나요?`로 표시한다. 두 번째 질문은 모든 달에 `그 목표를 위해 이번 달에 이루고 싶은 건 무엇인가요?`로 표시하며, 세 번째와 네 번째 질문은 명세 문구 그대로 사용한다. 날짜와 주 시작 요일에 따라 이번 달·이번 주 기간을 표시한다.

## 로그인

```text
+------------------------------------------------------------------+
| Aim2Day                                                           |
+------------------------------------------------------------------+
|                         로그인                                    |
|                                                                  |
|  이메일 또는 사용자명 [                                      ]   |
|  비밀번호             [                                      ]   |
|                                                                  |
|  [로그인]                                                        |
|  회원가입                                      비밀번호 재설정    |
+------------------------------------------------------------------+
```

로그인 성공 후 올해 목표가 없으면 네 질문 온보딩으로, 올해 목표가 있으면 대시보드로 이동한다. 회원가입과 비밀번호 재설정은 제출판 인증 절차를 제공한다.

## 대시보드

```text
+------------------------------------------------------------------+
| Aim2Day   [대시보드] [리포트] [설정]                  [로그아웃]  |
+------------------------------------------------------------------+
| 시간 경과                                                        |
| 올해 시간 경과 [██████░░░░]   이번 달 시간 경과 [████░░░░░░]      |
| 달력연도·달력월 기준 날짜 경과                                    |
| 목표 달성률과 별도 지표이며 목표 진행률에는 영향 없음             |
|                                                                  |
| 올해의 목표                                                       |
| [목표 A  진행률 40%] [목표 B  진행률 20%] [+ 연간 목표]           |
|  ※ 진행률은 목표별 확정 달성 기준 배점에 따른 값                  |
+------------------------------------------------------------------+
| 이번 달 목표                                                      |
| 목표 A > 월간 목표 A       진행률 __%   상태: 진행 중   [상세]     |
| 목표 B > 월간 목표 B       진행률 __%   상태: 진행 중   [상세]     |
|                                                                  |
| 목표 트리: 연간 목표 > 월간 목표 > 주간 목표                      |
+------------------------------------------------------------------+
| 오늘의 핵심 행동                                  [+ 행동 추가]   |
| [ ] 행동 내용 — 연결 주간 목표 — 수행일 YYYY.MM.DD                |
| [ ] 행동 내용 — 연결 주간 목표 — 수행일 YYYY.MM.DD                |
|                                                                  |
| 챙길 일                                             [+ 할 일 추가] |
| [ ] 생활상 할 일 — 기한 YYYY.MM.DD                               |
|                                                                  |
| 이번 달 달력                                                      |
| 월  화  수  목  금  토  일                                        |
|  1   2   3   4   5   6   7                                        |
|     목표 연결 행동/목표 기한: ●  ·  챙길 일 기한: ◆              |
+------------------------------------------------------------------+
| 최근 진행 기록: 날짜 · 변경 항목 · 메모                           |
+------------------------------------------------------------------+
```

오늘의 핵심 행동과 챙길 일은 별도 영역으로 보여준다. 행동은 사용자가 목표에 연결한 경우에만 핵심 행동이며, 과제라는 이유로 챙길 일에 자동 분류하지 않는다. 달력은 목표 연결 행동의 수행일 및 목표 기한과 목표 미연결 생활상 할 일의 기한을 기호·범례로 구분한다. 행동은 순서나 우선순위 없이 표시하고, 완료 처리는 항목별로 한다. 챙길 일(Maintenance)은 별도 분리·집계 제외 규칙을 유지하며 목표 진행률이나 집중 성과에 포함하지 않는다. 시간 경과 막대는 올해와 이번 달의 날짜 경과를 표시하고 목표 달성률과 별도 영역에서 보여주며, 목표 진행률에 반영하지 않는다. 상태는 완료·진행 중으로 표시하며, 종료일이 지난 미완료 목표도 상태 자체는 진행 중으로 유지하고 지연임을 함께 구분한다.

## 목표 상세 및 월·주 계획

```text
+------------------------------------------------------------------+
| [대시보드] > 목표 A                                               |
+------------------------------------------------------------------+
| 목표 A 제목                                      [수정] [상태 변경]|
| 기간: 2026년                         상태: 진행 중                |
| 연간 달성 기준 기반 진행률: 40%                                   |
| 확정 기준: [기준 1 완료 40점] [기준 2 미완료 60점] [기준 관리]    |
|                                                                  |
| 목표 트리                                                         |
| 연간 목표 A                                                       |
|  ├─ 월간 목표 A-1  진행 __%  [상세/계획]                           |
|  │   ├─ 주간 목표 A-1-a  진행 __%  [상세/계획]                     |
|  │   └─ 주간 목표 A-1-b  진행 __%  [상세/계획]                     |
|  └─ 월간 목표 A-2  진행 __%  [상세/계획]                           |
+------------------------------------------------------------------+
| 선택한 월간 목표: A-1                                             |
| 기간 [YYYY.MM]  결과/설명 [                                  ]   |
|                                                                  |
| 이번 주 목표                                                     |
| 직전 주 실제 진행: 완료한 일 / 남은 일 (기록 없으면 기록 없음)   |
| 다음 단계 [                                                ]     |
| 주간 목표 [                                              ]       |
| 측정 방식 (•) 체크리스트  ( ) 수치형   현재값 __ / 목표값 __     |
| 귀속 월간 목표 [A-1 선택]  ※ 주간 목표는 한 달에만 연결          |
| [주간 계획 저장]                                                  |
+------------------------------------------------------------------+
```

연간 목표 진행률은 사용자가 확정한 달성 기준의 배점 합계로 표시한다. 월간·주간 실행 진행률은 별도 표시한다. 체크리스트형 주간 진행률은 연결된 핵심 행동의 완료 비율이고, 수치형은 사용자가 입력한 실제 현재값으로 계산한다. 핵심 행동 완료만으로 수치값을 올리지 않는다. 월 경계를 넘는 주간 목표도 하나의 월간 목표에만 연결한다.

## 오늘 행동과 챙길 일

```text
+------------------------------------------------------------------+
| [대시보드] > 오늘 행동                         날짜 YYYY.MM.DD    |
+------------------------------------------------------------------+
| 오늘의 핵심 행동                                                 |
| 연결 주간 목표 [ 목표 선택                              v ]      |
| 행동 내용       [                                         ]      |
| 수행일          [ YYYY.MM.DD                            v ]      |
| [추가]                                                            |
|                                                                  |
| [ ] 행동 내용 — 주간 목표 — 수행일 YYYY.MM.DD       [완료] [수정] |
| [ ] 행동 내용 — 주간 목표 — 수행일 YYYY.MM.DD       [완료] [수정] |
|                                                                  |
| 챙길 일: 목표와 직접 연결되지 않는 생활상 할 일                   |
| 업무 내용       [                                         ]      |
| 수행일          [ YYYY.MM.DD                            v ]      |
| [추가]                                                            |
| [ ] 업무 내용 — 수행일 YYYY.MM.DD                    [완료] [수정] |
+------------------------------------------------------------------+
```

행동의 기본 수행일은 오늘이며 수정할 수 있다. 뒤늦게 기록할 때 실제 수행일을 입력하면 해당 날짜의 기간 리포트에 한 번 집계한다. 챙길 일(Maintenance)은 행동 및 목표 진행률 집계에서 제외한다. 과제도 사용자가 목표에 연결했는지에 따라 분류한다.

## 기본 리포트

```text
+------------------------------------------------------------------+
| [대시보드] > 기본 리포트                                          |
+------------------------------------------------------------------+
| 기간 [월 v] [2026.10 v]                 [조회]                    |
|                                                                  |
| 실제 수행일 기준 핵심 행동 기록                                  |
| 활동일: 기록된 날짜 목록       결과물: 기록된 결과                |
| 완료 행동: 기록된 항목          챙길 일(Maintenance): 집계 제외   |
|                                                                  |
| 목표별 달성 기준 진행률                                           |
| 목표       기간 시작     기간 말      변화(%p)    비교 메모       |
| 목표 A       20%          35%          +15%p      기록 시작 후    |
| 목표 B       기록 없음    20%          비교 불가  기준선 없음     |
|                                                                  |
| 기록이 없는 행동·활동일·결과는 추정하지 않습니다.                 |
| [돌아본 점 직접 작성] [다음 기간에 집중할 일 직접 작성]           |
| AI 회고 초안: 해당 기능은 현재 개발 중입니다.                     |
+------------------------------------------------------------------+
```

기간은 월·달력 분기·연간 중 선택한다. 리포트는 실제 수행일과 기록에 근거하며 챙길 일(Maintenance)을 제외한다. 시작 기준이나 종료 관측값이 없거나 기준·배점 변경으로 직접 비교할 수 없으면 비교 불가 사유를 표시한다. AI 회고는 안내만 제공하며 키 입력·결제·AI 호출은 제공하지 않는다.

## 검토 항목

- 첫날의 연간 목표 배점 기준을 언제 확정할지 미정이다. 초안 입력과 배점 합계 100점 확정의 시점 및 확정 전 진행률 표시 방식을 결정해야 한다.
- 온보딩 작성 도중 화면을 나갔다가 다시 돌아온 경우 입력 내용을 어떻게 처리할지 미정이다. 작성 내용 임시 보존 여부와 이어쓰기 또는 처음부터 시작하는 방식을 결정해야 한다.
